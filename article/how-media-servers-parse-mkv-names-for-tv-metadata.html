How Media Servers Parse MKV Names for TV Metadata

Media servers like Plex, Jellyfin, and Emby rely on automated parsing engines to translate unstructured MKV filenames into organized TV show libraries. By using regular expressions, string tokenization, and hierarchical folder inspection, these systems isolate key data—such as the series title, season number, and episode index—and match it against online databases like TheMovieDB (TMDB) and TheTVDB to download accurate season metadata, artwork, and episode descriptions.

1. Regex Pattern Matching and Tokenization

The core parsing engine uses Regular Expressions (regex) to identify standardized numbering patterns within the filename. Common patterns the parser looks for include:

  • Standard SXXEYY format: Show.Name.S01E05.mkv
  • Alternate delimiter formats: Show_Name_s1e5.mkv or Show Name - 1x05.mkv
  • Multi-episode files: Show.Name.S01E01-E02.mkv

When an MKV file is scanned, the parser evaluates the text against a list of pre-configured regex patterns. The numbers immediately following the "S" (or preceding the "x") are extracted as the Season integer, while the numbers following the "E" (or after the "x") are assigned to the Episode integer.

2. Stripping "Scene" Tags and Technical Noise

MKV files frequently contain metadata tags within their filenames that can interfere with standard title identification. Parsers utilize exclusion filters and stop-word dictionaries to strip non-essential information, including:

  • Resolution and source tags: 1080p, 4K, UHD, WEBRip, BluRay, HDTV
  • Encoding codecs: x264, x265, HEVC, AV1, 10bit
  • Audio formats: AAC, DTS-HD, TrueHD, Atmos, 5.1
  • Release groups and checksums: -[GroupName], [1234ABCD]

Once these tokens are identified and removed, the parser isolates the cleanest remaining string, which it designates as the Show Title and optional release year.

3. Directory Hierarchy Analysis

If a filename is ambiguous or lacks a season indicator (e.g., 01 - Pilot.mkv), media servers traverse up the directory tree to gather context.

The parser inspects parent folder names for cues:

  • Series Folder: /TV Shows/Breaking Bad (2008)/ provides the definitive show title and year.
  • Season Folder: /Season 01/ or /Specials/ explicitly establishes the season context for any files nested inside.

If the file naming contradicts the folder naming, media servers generally prioritize the season designated by the parent folder structure or combine both data points to build a high-confidence match candidate.

4. Database Querying and Metadata Association

After extracting the clean title, year, season, and episode index, the media server issues an API call to a metadata provider (such as TMDB or TheTVDB).

The process follows these steps:

  1. Title Search: The server queries the database with the extracted title and release year to obtain a unique Show ID.
  2. Season Order Matching: The server queries the specific Season ID associated with the Show ID based on the parsed season number.
  3. Episode Data Extraction: The server matches the episode number to the metadata entry within that season, pulling summaries, guest stars, air dates, and thumbnails.
  4. Local Storage: The MKV container is indexed in the server’s local database, linking the physical file path directly to the retrieved metadata ID.
