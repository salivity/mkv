Can MKV Store HE-AAC v2 with Parametric Stereo?

The Matroska (MKV) multimedia container fully supports High-Efficiency Advanced Audio Coding version 2 (HE-AAC v2) along with its Parametric Stereo (PS) feature. Because MKV is designed as a flexible, codec-agnostic container, it can store the full MPEG-4 Audio bitstream without discarding or altering the high-efficiency extensions. This article explains how MKV encapsulates HE-AAC v2 streams, how Parametric Stereo operates within the container, and what is required for proper playback.

How MKV Handles HE-AAC v2

Matroska identifies AAC audio streams using the standard A_AAC Codec ID. To accommodate HE-AAC v2, MKV places the stream's configuration data inside the CodecPrivate container header element as an AudioSpecificConfig structure.

This configuration informs the demuxer and decoder about:

  • Core AAC-LC: The base low-complexity audio data (typically encoded as a single mono channel to save bandwidth).
  • Spectral Band Replication (SBR): The extension that reconstructs higher-frequency audio content (HE-AAC v1).
  • Parametric Stereo (PS): The extension that describes the stereo image using metadata (HE-AAC v2).

Because MKV passes this bitstream directly to the decoder, the Parametric Stereo metadata remains intact inside the audio frames.

How Parametric Stereo Functions Inside the Container

Parametric Stereo achieves high audio quality at extremely low bitrates (typically 16–48 kbps) by encoding the audio as a single mono channel accompanied by a small sideband stream of spatial parameters (such as inter-channel intensity differences and phase differences).

Within an MKV file:

  1. The container multiplexes the audio packets alongside video and subtitle tracks.
  2. The packet payload contains both the mono core audio and the embedded SBR/PS extension data.
  3. The container's track header typically reports the stream as 2-channel stereo, reflecting the intended final output format rather than the mono core.

Playback and Decoder Compatibility

While MKV has no issue storing HE-AAC v2 with Parametric Stereo, correct audio reproduction depends on the decoder:

  • HE-AAC v2 Capable Decoders: Modern media players (such as VLC, mpv, and players utilizing FFmpeg or CoreAudio) read the Parametric Stereo metadata and reconstruct the full stereo soundstage.
  • Legacy AAC Decoders: If an older decoder does not support HE-AAC v2, it will ignore the SBR and PS extensions and decode only the core stream, resulting in mono audio with reduced high-frequency response (fallback compatibility).

Muxing Tools

Standard multiplexing tools handle HE-AAC v2 in MKV without special workarounds:

  • MKVToolNix (mkvmerge): Automatically parses AAC bitstreams with SBR and PS data, correctly writing the AudioSpecificConfig to ensure decoders recognize the stream as HE-AAC v2.
  • FFmpeg: Preserves the complete HE-AAC v2 stream when remuxing audio into the Matroska container using the stream copy (-c:a copy) command.
