Convert MKV to MP4 Without Re-encoding with FFmpeg

This article explains how to quickly change an MKV video file into an MP4 container using FFmpeg without re-encoding the underlying media streams. By using a process called remuxing (stream copying), you can switch the container format in just a few seconds while preserving the original video and audio quality with zero loss.

The Fast Remux Command

To convert an MKV container to MP4 without re-encoding, use the -c copy flag:

ffmpeg -i input.mkv -c copy output.mp4

How the Command Works

  • -i input.mkv: Specifies the path to your source MKV file.
  • -c copy: Tells FFmpeg to bypass the decoding and encoding pipeline, copying all video, audio, and subtitle streams directly into the target container.
  • output.mp4: Defines the name and format of the newly created file.

Because this command skips the resource-intensive encoding process, the conversion operates at the speed of your storage drive's read and write capabilities.

Handling Potential Compatibility Issues

While stream copying is fast, MP4 containers have stricter codec requirements than MKV containers.

Incompatible Audio (e.g., DTS to AAC)

If the MKV contains an audio format unsupported by your target MP4 player (such as DTS or Vorbis), you can copy the video stream while encoding only the audio to AAC:

ffmpeg -i input.mkv -c:v copy -c:a aac output.mp4

Incompatible Subtitles

MKV files often use ASS/SSA or PGS subtitles, which are not natively supported in standard MP4 containers. To convert text-based subtitles to the MP4-compatible mov_text format, use:

ffmpeg -i input.mkv -c:v copy -c:a copy -c:s mov_text output.mp4

If you do not need subtitles, you can exclude them entirely to avoid errors:

ffmpeg -i input.mkv -c copy -sn output.mp4
