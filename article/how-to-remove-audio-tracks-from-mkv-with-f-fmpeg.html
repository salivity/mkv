How to Remove Audio Tracks from MKV with FFmpeg

Removing unwanted foreign audio tracks from an MKV file using FFmpeg allows you to reduce file size and declutter media streams without losing video quality. By leveraging FFmpeg's stream mapping and stream-copying capabilities, you can strip unnecessary languages in seconds without having to re-encode the entire video.

Step 1: Identify the Audio Streams

Before removing any tracks, inspect the streams contained inside the MKV file to locate the specific audio track you want to keep or discard. Open your terminal or command prompt and run:

ffmpeg -i input.mkv

Look at the output under the stream mapping section. You will see streams listed in the format Stream #0:0, Stream #0:1, Stream #0:2, etc. For example:

  • Stream #0:0(eng): Video: h264 ...
  • Stream #0:1(jpn): Audio: aac ...
  • Stream #0:2(eng): Audio: ac3 ...
  • Stream #0:3(ger): Audio: ac3 ...

Note the stream index numbers or the language codes you wish to keep or exclude.

Step 2: Extract Only the Desired Streams

To strip unwanted tracks and keep only a specific audio track, use the -map option along with the -c copy flag. The -c copy flag ensures that the video, selected audio, and subtitle streams are copied directly without re-encoding, preserving 100% of the original quality.

If you want to keep the video (0:v) and only the English audio track (0:2 from the example above), run:

ffmpeg -i input.mkv -map 0:v -map 0:2 -map 0:s? -c copy output.mkv
  • -map 0:v selects all video tracks.
  • -map 0:2 selects the specific audio track.
  • -map 0:s? optionally keeps all subtitle tracks if they exist.
  • -c copy copies the streams without re-encoding.

Step 3: Remove Specific Audio Tracks by Negative Mapping

Alternatively, if an MKV file contains multiple foreign audio tracks and you want to exclude just one or two specific streams, you can use negative mapping with the - prefix.

To keep all streams except the German audio track at index 0:3:

ffmpeg -i input.mkv -map 0 -map -0:3 -c copy output.mkv
  • -map 0 selects all streams from the input file.
  • -map -0:3 explicitly removes stream index 3 (the German audio).

Step 4: Filter Audio Tracks by Language Metadata

If the MKV file has proper language tags metadata, you can select tracks based on the language code rather than stream index numbers:

ffmpeg -i input.mkv -map 0:v -map 0:m:language:eng -map 0:s? -c copy output.mkv

This command selects the video, all audio tracks tagged with English (eng), and all subtitles, effectively stripping out any audio tracks marked with other languages.
