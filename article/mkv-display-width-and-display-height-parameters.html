MKV Display Width and Display Height Parameters

In a Matroska (MKV) container, the rendered dimensions of a video stream are controlled independently of the underlying pixel storage resolution. This article outlines the specific Matroska elements that govern display geometry, focusing on DisplayWidth and DisplayHeight, how they interact with DisplayUnit, and how encoded resolution and cropping parameters influence the final playback aspect ratio.

Core Display Elements

Within the Matroska specification, video track properties are defined inside the TrackEntry element, specifically under the Video sub-element. The two primary parameters governing playback dimensions are:

  • DisplayWidth (Element ID: 0x54B0): Defines the target rendering width of the video frame.
  • DisplayHeight (Element ID: 0x54BA): Defines the target rendering height of the video frame.

When media players render an MKV video, they use these values rather than the raw pixel grid to determine the frame's aspect ratio on screen.

The Role of DisplayUnit

The interpretation of DisplayWidth and DisplayHeight depends on the DisplayUnit (Element ID: 0x54B2) parameter. If omitted, it defaults to pixels (0).

The available modes for DisplayUnit are:

  • 0 (Pixels): DisplayWidth and DisplayHeight specify the target display resolution directly in pixel dimensions.
  • 1 (Centimeters): The values represent physical display dimensions in centimeters.
  • 2 (Inches): The values represent physical display dimensions in inches.
  • 3 (Display Aspect Ratio): DisplayWidth and DisplayHeight act purely as a ratio (for example, 16 and 9) rather than absolute pixel targets.

Encoded Resolution vs. Display Resolution

To calculate anamorphic video or non-square pixel aspect ratios (PAR), players compare the display parameters with the encoded pixel grid parameters:

  • PixelWidth (Element ID: 0xB0): The actual horizontal number of encoded pixels in the video stream.
  • PixelHeight (Element ID: 0xBA): The actual vertical number of encoded pixels in the video stream.

If an MKV file contains a PixelWidth of 720 and a PixelHeight of 480 (standard NTSC DVD resolution), setting DisplayWidth to 854 and DisplayHeight to 480 instructs the player to stretch the video to a standard 16:9 widescreen presentation during playback without re-encoding the stream.

Pixel Cropping Parameters

If cropping is defined, players must apply the crop before applying the DisplayWidth and DisplayHeight scaling:

  • PixelCropTop (Element ID: 0x54BB)
  • PixelCropBottom (Element ID: 0x54BA in older specs / 0x54AA)
  • PixelCropLeft (Element ID: 0x54CC)
  • PixelCropRight (Element ID: 0x54DD)

When present, the visible portion of the frame (PixelWidth - PixelCropLeft - PixelCropRight by PixelHeight - PixelCropTop - PixelCropBottom) is scaled to fill the geometry specified by DisplayWidth and DisplayHeight.
