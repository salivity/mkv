How to Remove Subtitles from MKV with FFmpeg

Removing all subtitle tracks from an MKV (Matroska) container using FFmpeg can be done quickly without re-encoding your video or audio streams. By utilizing stream copying along with specific subtitle-disabling flags, you can generate a clean MKV file in seconds while preserving the original video and audio quality.

The Standard Command

The simplest and most efficient command to strip all subtitle streams from an MKV file is:

ffmpeg -i input.mkv -c copy -sn output.mkv

Parameter Breakdown

  • -i input.mkv: Specifies the path to the input MKV file.
  • -c copy: Tells FFmpeg to copy all streams directly without re-encoding, which ensures the process is extremely fast and causes zero loss in visual or audio quality.
  • -sn: Stands for "subtitle no." This parameter disables the inclusion of any subtitle streams in the output file.
  • output.mkv: Specifies the name and container format for the generated output file.

Alternative Method: Using Stream Mapping

You can achieve the same result using explicit stream mapping flags (-map). This method gives you fine-grained control if you are working with complex files containing multiple video or audio tracks:

ffmpeg -i input.mkv -map 0 -map -0:s -c copy output.mkv

Parameter Breakdown

  • -map 0: Selects all streams (video, audio, subtitles, attachments) from the first input file.
  • -map -0:s: The negative mapping specifically excludes all subtitle streams from the selection.
  • -c copy: Copies the remaining selected streams (video and audio) without re-encoding.

Batch Processing Multiple MKV Files

If you have a folder full of MKV files and want to remove subtitles from all of them at once, you can run a loop in your command line.

Windows (Command Prompt)

for %i in (*.mkv) do ffmpeg -i "%i" -c copy -sn "clean_%i"

Linux / macOS (Bash)

for file in *.mkv; do
    ffmpeg -i "$file" -c copy -sn "clean_${file}"
done
