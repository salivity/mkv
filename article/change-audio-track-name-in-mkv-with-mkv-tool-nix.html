Change Audio Track Name in MKV with MKVToolNix

This guide explains how to quickly change the track name of a specific audio stream in a Matroska (MKV) file using MKVToolNix. By utilizing the mkvpropedit command-line tool included in the MKVToolNix suite, you can modify track metadata in place within seconds without the need to re-encode or remux the entire video file.

Step 1: Identify the Audio Track

Before modifying the track name, you need to identify the track number or track ID of the target audio stream. Run mkvmerge to inspect the file:

mkvmerge -i "your_video.mkv"

The output will list all streams in the file along with their track IDs and types, for example:

Track ID 0: video (MPEG-4p10/AVC/h.264)
Track ID 1: audio (AAC)
Track ID 2: audio (AC-3/E-AC-3)
Track ID 3: subtitles (SubRip/SRT)

Step 2: Change the Audio Track Name Using mkvpropedit

To modify the audio track name directly in the file, use the mkvpropedit command with the --edit and --set name= parameters.

Method A: Select by Audio Track Index

You can target audio tracks using track:a<n>, where a1 refers to the first audio track, a2 to the second, and so on:

mkvpropedit "your_video.mkv" --edit track:a1 --set name="English 5.1 Surround"

Method B: Select by Track ID

Alternatively, you can select the track directly using the Track ID found in Step 1:

mkvpropedit "your_video.mkv" --edit track:2 --set name="Commentary Track"

Step 3: Verify the Changes

To confirm that the track name has been updated successfully, inspect the file again:

mkvmerge -i "your_video.mkv"

The metadata is updated immediately in the existing file without creating a temporary copy or altering the video/audio streams.
