Extract Embedded TTF and OTF Fonts from MKV

Matroska (MKV) video files often contain embedded TrueType (TTF) and OpenType (OTF) font files to ensure that styled subtitles (such as ASS/SSA) render identically across different media players. Extracting these font attachments can be done quickly and without re-encoding the video file by using specialized Matroska manipulation tools like MKVToolNix or command-line utilities like FFmpeg. This guide explains the most effective methods to extract embedded fonts from any MKV container.

Method 1: Using MKVToolNix GUI (Header Editor)

MKVToolNix is the official, open-source toolset for Matroska files. It includes a built-in graphical interface to inspect and extract attachments directly.

  1. Download and install MKVToolNix.
  2. Open MKVToolNix GUI.
  3. In the left-hand sidebar, click on the Header editor tab.
  4. Drag and drop your MKV file into the window.
  5. In the tree view on the left, scroll down and expand the Attachments section.
  6. Right-click the font file (identified by .ttf or .otf extensions, or the font/ttf / font/otf MIME type).
  7. Select Save attachment (or select multiple and choose Save all attachments) to export the font files to your desired folder.

Method 2: Using FFmpeg (Command Line)

If you prefer using the command line or need to automate the extraction process via scripts, FFmpeg can extract all embedded attachments at once.

  1. Ensure FFmpeg is installed and accessible in your system's PATH.
  2. Open a terminal or command prompt in the directory containing your MKV file.
  3. Run the following command:
ffmpeg -dump_attachment:t "" -i input.mkv

Replace input.mkv with the name of your video file.

This command instructs FFmpeg to dump all stream attachments (type t) found within the container into the current working directory, automatically preserving their original TTF or OTF filenames.

Method 3: Using gMKVExtractGUI

gMKVExtractGUI is a lightweight, dedicated extraction interface that runs on top of MKVToolNix’s mkvextract utility. It is ideal for batch extractions.

  1. Download gMKVExtractGUI and place its executable inside your installed MKVToolNix directory (or point the program to mkvextract.exe).
  2. Launch gMKVExtractGUI.exe.
  3. Drop your MKV file into the Input File field.
  4. The program will list all streams, chapters, and attachments. Check the boxes next to the Attachments (TTF/OTF fonts) you wish to extract.
  5. Choose an Output Directory and click Extract.
