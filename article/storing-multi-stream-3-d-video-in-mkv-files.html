Storing Multi-Stream 3D Video in MKV Files

The Matroska (MKV) container format fully supports storing multi-stream and stereoscopic 3D video, including side-by-side (SBS) formats. Through its extensible architecture and native stereoscopic metadata tags, MKV can encapsulate separate video streams for each eye or contain a single video stream encoded with frame-packing methods. This flexibility makes MKV one of the most widely used containers for distributing 3D content across modern media players and VR headsets.

Matroska’s Native Stereoscopic Support

The Matroska specification includes dedicated header elements specifically designed for 3D media. The most critical element is StereoMode, which tells the playback software exactly how the 3D video is structured.

MKV supports several stereoscopic configurations via the StereoMode tag:

  • Side by Side (Left Eye First): StereoMode = 1
  • Side by Side (Right Eye First): StereoMode = 11
  • Top-Bottom / Over-Under: StereoMode = 2 or StereoMode = 3
  • Separate Tracks / Multi-Stream: MKV allows independent video tracks mapped to individual eyes.

Multi-Stream vs. Single-Stream SBS

When handling 3D video, MKV can store the data in two distinct ways:

1. Dual Independent Video Streams (Multi-Stream)

MKV can hold two completely separate, full-resolution video streams in the same file—one stream for the left eye and another for the right eye. Advanced codecs like MVC (Multiview Video Coding, an extension of H.264 used on 3D Blu-rays) can also be packaged within MKV. The player reads both streams simultaneously and renders them based on the display device's requirements, such as generating an on-the-fly side-by-side output.

2. Single-Stream Packed SBS

In standard Side-by-Side implementations, both the left and right perspectives are compressed into a single video frame (either Half-SBS or Full-SBS). MKV tags this single track with the appropriate StereoMode flag so the player automatically stretches, separates, or displays the halves correctly without manual user adjustment.

Hardware and Software Playback

For an MKV file with multi-stream or SBS 3D to display properly:

  • Muxing Tools: Tools like mkvmerge (part of MKVToolNix) allow users to set the StereoMode flag or add multiple video tracks during the muxing process.
  • Player Compatibility: Software players (such as Kodi, VLC, PotPlayer, or VR media players like Skybox) read the MKV header tags and format the video for 3D TVs, VR displays, or stereoscopic projectors.
