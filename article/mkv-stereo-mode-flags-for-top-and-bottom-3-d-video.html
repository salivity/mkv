MKV StereoMode Flags for Top-and-Bottom 3D Video

The Matroska (MKV) container stores stereoscopic 3D metadata directly within its track header parameters, using a dedicated integer element to define layout orientation and eye arrangement. For top-and-bottom (also known as over-under) 3D content, the container relies on the StereoMode EBML element to instruct compatible media players, splitters, and displays on how to unpack and render the vertically stacked frames for the left and right eyes without requiring changes to the underlying video stream.

The Matroska Track Hierarchy and StereoMode Element

Inside the structure of an MKV file, metadata is organized in an Extensible Binary Meta Language (EBML) tree. Video settings exist within the Segment -> Tracks -> TrackEntry -> Video hierarchy.

To signal 3D video, Matroska provides the StereoMode element:

  • Element Name: StereoMode
  • EBML ID: 0x53B8
  • Data Type: Unsigned Integer (uinteger)

Specific Flag Values for Top-and-Bottom 3D

Matroska differentiates between layouts based on both orientation and eye dominance (which eye occupies the top half of the frame). For top-and-bottom configurations, two primary flag values are used:

  • Value 2: Top - bottom (Right eye is first / top)
  • Value 3: Top - bottom (Left eye is first / top)

When set to 3, the video renderer reads the upper half of each decoded frame as the left-eye view and the lower half as the right-eye view. If set to 2, the upper half is assigned to the right eye and the lower half to the left eye.

Decoding and Presentation Behavior

The StereoMode element operates purely at the container level. The underlying video stream (typically encoded with AVC/H.264 or HEVC/H.265) remains a standard 2D video containing both images stacked vertically.

When a compliant player reads the 0x53B8 flag:

  1. It parses the video frame dimensions (e.g., standard 1920x1080 for Half Top-and-Bottom, or 1920x2160 for Full Top-and-Bottom).
  2. It splits the vertical resolution in half.
  3. It assigns each half to the appropriate eye buffer according to whether flag 2 or 3 is defined.
  4. It stretches or scales the half-resolution images to the target display aspect ratio for 3D presentation (e.g., frame sequential, polarized, or VR headset display).

Inspecting and Modifying the Flag

The StereoMode parameter can be added, inspected, or modified without re-encoding the video stream. Software suites such as MKVToolNix expose this property via GUI header editors or the command-line utility mkvpropedit by modifying the stereo-mode property on the target video track.
