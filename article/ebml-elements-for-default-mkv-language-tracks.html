EBML Elements for Default MKV Language Tracks

In a Matroska (MKV) multimedia container, determining which audio or subtitle track plays by default relies on specific Extensible Binary Meta Language (EBML) elements embedded within track headers. This article details the core EBML elements responsible for defining track language, default playback status, and track priority in MKV files.

The TrackEntry Container

All track configuration elements reside inside the Tracks master element (0x1654AE6B), nested within individual TrackEntry elements (0xAE). Each TrackEntry represents an independent stream (video, audio, or subtitle) and contains metadata describing its language and default behavior.

Key EBML Elements Determining Default Tracks

1. FlagDefault (0x88)

  • Data Type: Unsigned Integer (Boolean: 0 or 1)
  • Default Value: 1 (if omitted)
  • Function: Informs media players that the track is eligible for automatic selection upon opening the file. When set to 1 (True), the player treats this stream as the default choice for its specific TrackType, unless user preferences or forced flags override it.

2. LanguageBCP47 (0x22B59D)

  • Data Type: UTF-8 String
  • Function: Contains the IETF BCP 47 language tag (e.g., en, en-US, ja, pt-BR) identifying the track's language. Media players match this value against the user's preferred playback language to decide if a track marked as FlagDefault should be used.

3. Language (0x22B59C)

  • Data Type: String (Legacy)
  • Default Value: und (Undetermined)
  • Function: Contains the 3-letter ISO 639-2 language code (e.g., eng, jpn, fre). Modern specifications recommend LanguageBCP47, but legacy players rely on this element to detect track language for default selection.

4. FlagForced (0x55AA)

  • Data Type: Unsigned Integer (Boolean: 0 or 1)
  • Default Value: 0 (if omitted)
  • Function: Primarily used for subtitles. When set to 1, it signals that the track contains essential context (such as translations for foreign-language dialogue in an otherwise native-language track) and should be rendered regardless of whether subtitles are generally disabled by the user.

5. TrackType (0x83)

  • Data Type: Unsigned Integer
  • Function: Identifies the media type (e.g., 1 for Video, 2 for Audio, 17 for Subtitles). Default flag evaluation is isolated per TrackType, allowing one default track per category.

Player Evaluation Logic

When an MKV file is opened, media players generally resolve default tracks using the following hierarchy:

  1. User Preference: The player checks if a track's LanguageBCP47 or Language matches the user's configured preferred language.
  2. FlagDefault Priority: Among matching language tracks (or if no preference is set), the player selects the track where FlagDefault is set to 1.
  3. Track Order Fallback: If multiple tracks share the same language and default flags, or if no default flag is set, players typically fall back to the track with the lowest TrackNumber (0xD7).
