Can MKV Files Contain Blu-ray PGS Subtitles?

Yes, the Matroska (MKV) container format fully supports bitmap-based Presentation Graphic Stream (PGS) subtitle tracks extracted directly from Blu-ray sources. This article covers how MKV handles native PGS subtitles, the advantages of keeping them in their original format, compatibility factors across media players and streaming servers, and options for managing these tracks during Blu-ray extraction.

How MKV Handles PGS Subtitles

Blu-ray discs use Presentation Graphic Stream (PGS) subtitles, which are encoded as a series of timed bitmap images rather than plain text. Unlike text-based formats (such as SRT), PGS tracks store exact graphic renderings of fonts, colors, positioning, and special symbols.

The Matroska container is an open-standard, extensible multimedia container designed to encapsulate almost any video, audio, or subtitle stream. When extracting a Blu-ray movie using software like MakeMKV or MKVToolNix, the PGS stream is copied directly into the MKV file as a native subtitle track with the codec identifier S_HDMV/PGS. No conversion, compression, or quality loss occurs during this process.

Benefits of Keeping Native PGS Subtitles

  • Identical Visual Presentation: Subtitles retain the exact font, size, styling, and screen placement intended by the disc creators, including specialized formatting for forced subtitles or non-standard languages.
  • No OCR Errors: Converting bitmap subtitles to text formats requires Optical Character Recognition (OCR), which can introduce spelling mistakes, missed punctuation, or corrupted characters. Retaining PGS eliminates this risk entirely.
  • Fast Processing: Remuxing a PGS track into an MKV container takes only seconds because it involves simply copying the existing data stream without re-encoding.

Playback and Compatibility

While MKV fully supports PGS tracks, playback capability depends on the client device and software player being used.

Software Players

Most dedicated desktop media players handle MKV files with PGS subtitles natively without issues:

  • VLC Media Player (Windows, macOS, Linux)
  • mpv and MPC-HC / MPC-BE (Windows)
  • Kodi (Cross-platform)
  • Infuse (Apple TV, iOS, macOS)

Media Servers (Plex, Emby, Jellyfin)

Streaming platforms can read PGS subtitles embedded in MKV files, but behavior varies based on client hardware:

  • Direct Play: High-performance streaming clients, such as the Nvidia Shield TV or devices running Kodi, can render PGS subtitles natively without straining the media server.
  • Transcoding (Burn-in): Devices with limited subtitle support—such as web browsers, older Smart TVs, and certain streaming sticks—cannot render PGS bitmaps on the fly. In these cases, the media server must decode the video, "burn" the PGS images directly onto the video frames, and re-encode the stream in real time. This requires substantial CPU or GPU processing power on the server host.

Alternative: Converting PGS to SRT

If widespread device compatibility is a priority or server hardware cannot handle real-time transcoding, PGS subtitles can be converted to text-based SRT (SubRip) tracks. Tools such as Subtitle Edit, BDSup2Sub, or OCR features built into HandBrake allow users to scan the bitmap images and generate lightweight text subtitle tracks, which can then be remuxed back into the MKV file alongside or in place of the original PGS track.
