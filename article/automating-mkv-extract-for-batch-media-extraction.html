Automating MKVExtract for Batch Media Extraction

MKVExtract, a core component of the MKVToolNix suite, provides command-line capabilities for demuxing Matroska (.mkv) container files into individual video, audio, subtitle, and chapter streams. This article explains how to integrate MKVExtract into automated scripting environments—such as Bash, PowerShell, and Python—to streamline high-volume media processing. It covers track discovery, dynamic command generation, batch execution patterns, and best practices for robust automation pipelines.

Prerequisites and Core Syntax

Before automating, ensure mkvextract and mkvmerge are installed and available in your system's PATH.

The fundamental syntax for extracting tracks using MKVExtract is:

mkvextract tracks <source-file.mkv> <track-id>:<output-file.ext>

Because track IDs vary across different files, hardcoding track numbers can lead to incorrect extractions. A reliable automation pipeline always pairs mkvextract with mkvmerge to inspect the source file first.

Inspecting Tracks Programmatically

To automate extraction dynamically, use mkvmerge -J <file.mkv> to output the container's structure in JSON format. This output contains detailed information about:

  • Track ID: The integer required by mkvextract.
  • Track Type: Audio, video, or subtitles.
  • Codec and Properties: Codec ID, language codes, default/forced flags, and track names.

By parsing this JSON output, scripts can identify specific streams (e.g., all English SRT subtitles or FLAC audio tracks) without manual inspection.

Automation Examples

1. Bash Scripting (Linux / macOS)

This Bash script uses jq to parse container data, dynamically locate English subtitle tracks, and extract them across all MKV files in a directory.

#!/usr/bin/env bash

for file in *.mkv; do
  [ -e "$file" ] || continue
  echo "Processing: $file"

  # Extract track ID and codec for English subtitles
  mkvmerge -J "$file" | jq -r '
    .tracks[] | 
    select(.type=="subtitles" and .properties.language=="eng") | 
    "\(.id) \(.properties.codec_id)"
  ' | while read -r track_id codec; do
    
    # Determine appropriate extension
    ext="sub"
    [[ "$codec" == *"UTF8"* ]] && ext="srt"
    [[ "$codec" == *"ASS"* ]] && ext="ass"

    output="${file%.mkv}_track${track_id}_eng.${ext}"
    
    echo "Extracting track $track_id to $output..."
    mkvextract tracks "$file" "${track_id}:${output}"
  done
done

2. PowerShell Scripting (Windows)

PowerShell natively handles JSON, making it well-suited for querying mkvmerge metadata and passing parameters to mkvextract.

Get-ChildItem -Filter *.mkv | ForEach-Object {
    $file = $_.FullName
    $baseName = $_.BaseName
    
    # Get file metadata as JSON
    $json = mkvmerge -J $file | ConvertFrom-Json
    
    # Find all audio tracks
    $audioTracks = $json.tracks | Where-Object { $_.type -eq "audio" }
    
    foreach ($track in $audioTracks) {
        $trackId = $track.id
        $lang = if ($track.properties.language) { $track.properties.language } else { "und" }
        $outputPath = Join-Path $_.DirectoryName "$($baseName)_audio_${trackId}_${lang}.aac"
        
        Write-Host "Extracting audio track $trackId from $($_.Name)"
        & mkvextract tracks $file "${trackId}:${outputPath}"
    }
}

3. Python Automation

Python provides greater control for complex workflows, such as conditional extraction, database logging, and error handling.

import json
import subprocess
from pathlib import Path

def extract_chapters_and_subs(mkv_path: Path):
    # Get JSON metadata
    cmd = ["mkvmerge", "-J", str(mkv_path)]
    result = subprocess.run(cmd, capture_output=True, text=True, check=True)
    metadata = json.loads(result.stdout)

    # 1. Extract Chapters if present
    if metadata.get("chapters"):
        chapter_out = mkv_path.with_suffix(".chapters.xml")
        subprocess.run(["mkvextract", "chapters", str(mkv_path), "-s", str(chapter_out)], check=True)

    # 2. Extract Subtitles
    extract_args = []
    for track in metadata.get("tracks", []):
        if track["type"] == "subtitles":
            track_id = track["id"]
            lang = track.get("properties", {}).get("language", "und")
            sub_out = mkv_path.with_name(f"{mkv_path.stem}_track{track_id}_{lang}.srt")
            extract_args.append(f"{track_id}:{sub_out}")

    if extract_args:
        subprocess.run(["mkvextract", "tracks", str(mkv_path)] + extract_args, check=True)

if __name__ == "__main__":
    for mkv_file in Path(".").glob("*.mkv"):
        print(f"Demuxing {mkv_file.name}...")
        extract_chapters_and_subs(mkv_file)

Best Practices for Automation

  • Multi-Track Demuxing in a Single Call: mkvextract can extract multiple tracks simultaneously by passing multiple <track-id>:<output-file> arguments, avoiding redundant passes over large video files.
  • Handling Exit Codes: Check process return values. A return code of 0 indicates success, 1 indicates warnings (such as missing frames), and 2 indicates a critical error.
  • Extraction Modes: In addition to tracks, use dedicated extraction modes like mkvextract chapters <file> for chapter extraction, mkvextract attachments <file> for embedded fonts and covers, and mkvextract tags <file> for XML metadata.
  • Concurrency: For multi-core processing, limit parallel extractions based on disk I/O throughput rather than CPU count, as demuxing large files is primarily an I/O-bound operation.
