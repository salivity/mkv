Extract All Subtitles from MKV with FFmpeg

Extracting all subtitle streams simultaneously from an MKV file using FFmpeg requires using stream mapping to route each subtitle track to its own output file in a single command execution. This guide explains how to identify your subtitle streams using FFprobe and run the FFmpeg command that extracts every subtitle track concurrently without re-encoding.

Step 1: Identify the Subtitle Tracks

Before extracting, check the number of subtitle streams and their formats (e.g., SRT, ASS, PGS) by running:

ffprobe -v error -select_streams s -show_entries stream=index:stream_tags=language,title -of csv=p=0 input.mkv

This displays the stream index numbers along with their language codes and titles.

Step 2: The Simultaneous Extraction Command

FFmpeg does not automatically split streams into separate files with wildcards, so you must define an output file for each subtitle stream using the -map option. To extract multiple subtitle streams at the same time, execute:

ffmpeg -i input.mkv \
  -map 0:s:0 -c:s:0 copy output_sub1.srt \
  -map 0:s:1 -c:s:1 copy output_sub2.srt \
  -map 0:s:2 -c:s:2 copy output_sub3.srt

Breakdown of the Command

  • -i input.mkv: Specifies the input file.
  • -map 0:s:0: Selects the first subtitle stream from the first input (0).
  • -map 0:s:1: Selects the second subtitle stream.
  • -map 0:s:2: Selects the third subtitle stream.
  • -c:s:X copy: Copies the subtitle stream without re-encoding, preserving the original formatting and timestamps.
  • output_subX.srt: The designated output filename for each stream.

Handling Different Subtitle Formats

Ensure the output file extension matches the internal format of the stream:

  • Use .srt for SubRip text subtitles.
  • Use .ass for Advanced SubStation Alpha subtitles.
  • Use .sup for image-based PGS/Blu-ray subtitles (as they cannot be saved directly into text .srt without OCR conversion).
