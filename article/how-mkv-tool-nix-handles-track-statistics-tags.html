How MKVToolNix Handles Track Statistics Tags

MKVToolNix automatically calculates and writes track statistics tags whenever it multiplexes streams into a Matroska (MKV) container. These tags provide essential metadata about individual video, audio, and subtitle tracks—including duration, bitrates, frame counts, and byte sizes—allowing media players to read stream properties without scanning the entire file. Users have full control over this process, with options to generate fresh statistics, preserve existing tags, or disable track statistics tags entirely.

What Are Track Statistics Tags?

When MKVToolNix processes a file, its underlying engine, mkvmerge, calculates metadata for each individual track during the muxing process. It writes these metrics as standard Matroska track tags using specific naming conventions:

  • BPS: The average bits per second (bitrate) for the track.
  • DURATION: The total playback duration of the track down to the nanosecond.
  • NUMBER_OF_FRAMES: The total count of frames or packets in the track.
  • NUMBER_OF_BYTES: The exact size of the track payload in bytes.
  • _STATISTICS_WRITING_APP: The specific application and version used to create the tags (e.g., mkvmerge vXX.X.X).
  • _STATISTICS_WRITING_DATE_UTC: The precise UTC timestamp when the statistics were generated.
  • _STATISTICS_TAGS: A list specifying which track statistics tags were written.

How MKVToolNix Processes Statistics During Multiplexing

By default, MKVToolNix behaves in the following manner when generating an MKV file:

  1. Analysis and Recalculation: During the multiplexing pass, MKVToolNix counts every frame, packet, and byte written for each track to ensure 100% accuracy.
  2. Replacing Outdated Tags: If the source container already contains track statistics tags, MKVToolNix deletes the old tags by default and replaces them with recalculated values. This prevents incorrect metadata if tracks have been cut, appended, or delayed.
  3. Container-Level Independence: These statistics are stored as Matroska tag elements linked directly to each track's unique TrackUID, keeping track-specific data separate from global file metadata.

Disabling or Modifying Track Statistics

While track statistics are helpful for media players, some workflows require omitting them (for instance, to achieve deterministic or bit-identical file outputs). MKVToolNix allows users to control this behavior:

  • In the GUI: Navigate to the Output tab and check the option labeled Disable track statistics tags before starting the multiplexing process. You can also set this as the default behavior in the application preferences.
  • Using the Command Line (mkvmerge): Add the --disable-track-statistics-tags switch to your command. This tells mkvmerge to skip the calculation and inclusion of track statistics tags entirely.

If track statistics tags are disabled, MKVToolNix simply writes the stream data without appending the additional track-level tag elements, leaving only the standard track headers and user-defined metadata.
