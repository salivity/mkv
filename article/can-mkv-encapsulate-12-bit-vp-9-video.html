Can MKV Encapsulate 12-Bit VP9 Video?

Matroska (MKV) fully supports the encapsulation of raw VP9 video bitstreams featuring 12-bit color sampling. By utilizing VP9 Profile 2 or Profile 3, high-bit-depth color data can be stored inside the Matroska container without compatibility barriers or stream modifications.

VP9 Profiles and 12-Bit Depth

The VP9 video coding standard defines four distinct profiles to handle various bit depths and chroma subsampling formats:

  • Profile 0: 8-bit depth with 4:2:0 chroma subsampling.
  • Profile 1: 8-bit depth with 4:2:2 or 4:4:4 chroma subsampling.
  • Profile 2: 10-bit and 12-bit depth with 4:2:0 chroma subsampling.
  • Profile 3: 10-bit and 12-bit depth with 4:2:2 or 4:4:4 chroma subsampling.

To encapsulate a 12-bit raw VP9 bitstream, the video must be encoded under Profile 2 or Profile 3. The raw stream contains the required sequence and frame headers that define bit depth, color space, and subsampling configurations.

Matroska Container Support for VP9

Matroska identifies VP9 tracks using the standard Codec ID V_VP9. The container acts as a bitstream-agnostic wrapper that packages raw VP9 frames directly into SimpleBlock or Block structures without altering the underlying compressed data.

Because Matroska does not enforce constraints on the codec's internal bit depth, it handles 12-bit payloads identical to standard 8-bit or 10-bit payloads. Additionally, the MKV specification includes optional Colour metadata elements (such as BitsPerChannel, MatrixCoefficients, and ChromaSiting), allowing container-level signaling of 12-bit color properties alongside the in-band bitstream parameters.

Muxing and Implementation

Standard multimedia utilities, including FFmpeg and MKVToolNix, support muxing raw 12-bit VP9 streams (.ivf or raw bitstream files) directly into MKV containers. During encapsulation:

  1. The raw VP9 stream is parsed for keyframes and temporal metadata.
  2. The track header is set to V_VP9.
  3. Frame data is mapped sequentially into cluster blocks.

Playback compatibility depends entirely on the downstream decoder's ability to decode VP9 Profile 2 and Profile 3 streams, as the MKV container itself introduces no limitations for 12-bit color reproduction.
