How to Set Default Audio Track in MKVToolNix

MKVToolNix provides powerful command-line utilities to modify track properties within Matroska (.mkv) files. This guide demonstrates how to use mkvpropedit to set a specific audio track as the default output without remuxing the entire file, as well as how to set it during a standard multiplexing process using mkvmerge.

Identifying Audio Track IDs

Before modifying properties, you need to identify the track number or ID of the audio streams in your file. Run the following command:

mkvmerge -i "input_file.mkv"

The output will list the tracks along with their IDs and types (e.g., Track ID 0: video, Track ID 1: audio (AAC), Track ID 2: audio (AC-3)).

Method 1: Using mkvpropedit (Instant In-Place Modification)

The mkvpropedit tool allows you to change track headers directly in the existing MKV file without re-encoding or rebuilding the file.

To set an audio track as default, use the --edit parameter followed by the track selector, then use --set flag-default=1.

Setting the First Audio Track as Default:

mkvpropedit "input_file.mkv" --edit track:a1 --set flag-default=1

Setting a Specific Track by Track ID:

If your desired audio track is Track ID 2, run:

mkvpropedit "input_file.mkv" --edit track:2 --set flag-default=1

Disabling Other Default Flags:

To ensure media players do not prioritize the wrong track, explicitly remove the default flag from the other audio tracks:

mkvpropedit "input_file.mkv" --edit track:a1 --set flag-default=0 --edit track:a2 --set flag-default=1

Method 2: Using mkvmerge (Creating a New File)

If you are already creating or remuxing an MKV file, use mkvmerge with the --default-track-flag option.

mkvmerge -o "output_file.mkv" --default-track-flag 1:no --default-track-flag 2:yes "input_file.mkv"

In this command:

  • 1:no disables the default flag on Track ID 1.
  • 2:yes enables the default flag on Track ID 2.
