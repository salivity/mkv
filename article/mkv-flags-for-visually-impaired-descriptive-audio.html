MKV Flags for Visually Impaired Descriptive Audio

Marking an audio track as visually impaired descriptive audio in a Matroska (MKV) container involves setting specific metadata flags defined by the Matroska specification. This article details the exact Matroska element used to identify descriptive audio tracks, how media players interpret these tags, and the specific commands required to apply them using standard tools like MKVToolNix and FFmpeg.

The Matroska Track Element: FlagVisualImpaired

In the Matroska specification, the primary flag for descriptive audio is the FlagVisualImpaired element (Element ID: 0x55EE).

  • Type: Boolean (0 for false, 1 for true)
  • Default Value: 0
  • Purpose: Set to 1 to indicate that the track contains audio descriptions suitable for visually impaired audiences.

When modern media players (such as VLC, MPV, or Kodi) read an MKV container with FlagVisualImpaired=1, they identify the track as "Audio Description" (AD) or "Descriptive Video Service" (DVS) and present it accordingly in the audio selection menu.

Setting the Flag Using MKVToolNix

MKVToolNix provides two ways to apply the visual impairment flag: lossless header editing with mkvpropedit or remuxing with mkvmerge.

Using mkvpropedit (No Remuxing Required)

To modify an existing MKV file in-place without remuxing the entire file:

mkvpropedit "movie.mkv" --edit track:a1 --set flag-visual-impaired=1

(Replace a1 with the specific audio track number, such as a2 for the second audio track).

Using mkvmerge (During Remuxing)

To set the flag while creating a new MKV file:

mkvmerge -o "output.mkv" --visual-impaired-flag 1:1 "input.mkv"

(The syntax 1:1 specifies Track ID 1 and flag value 1 [true]).

Setting the Flag Using FFmpeg

In FFmpeg, Matroska flags are mapped using the -disposition option. The disposition value corresponding to FlagVisualImpaired is visual_impaired.

ffmpeg -i "input.mkv" -map 0 -c copy -disposition:a:1 visual_impaired "output.mkv"

(The parameter -disposition:a:1 visual_impaired applies the flag to the second audio stream).

Recommended Complementary Metadata

For optimal compatibility across all media players and hardware devices, configure these complementary track properties alongside FlagVisualImpaired:

  • TrackName / Name: Set to a descriptive title, such as "English (Audio Description)" or "English (Descriptive Audio)".
  • Language: Set the proper BCP 47 or ISO 639-2 language code (e.g., eng).
  • FlagDefault: Set to 0 unless the descriptive track is intended to be the default audio stream for all viewers.
