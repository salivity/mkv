How to Set Default Track Flags in MKVMerge CLI

This guide demonstrates how to configure and automate default track flags in Matroska (.mkv) files using the mkvmerge command-line utility from the MKVToolNix suite. You will learn how to identify track IDs, apply the default track flag syntax to audio, video, and subtitle tracks, and implement terminal scripts in Bash and PowerShell for batch processing.

1. Identify Track IDs

Before modifying flags, determine the internal track IDs of your source file using mkvmerge -i or mkvmerge -J (for JSON output).

mkvmerge -i input.mkv

Example output:

File 'input.mkv': container: Matroska
Track ID 0: video (HEVC/H.265)
Track ID 1: audio (AAC) [language:und]
Track ID 2: audio (AC-3) [language:eng]
Track ID 3: subtitles (SubRip/SRT) [language:eng]

2. Setting Default Track Flags with MKVMerge

To set or unset default flags during remuxing, use the --default-track-flag option followed by the track_ID:bool parameter, where bool can be yes/no or 1/0.

Basic Syntax

mkvmerge -o <output.mkv> --default-track-flag <track_id>:<yes|no> <input.mkv>

Example: Setting Specific Audio and Subtitle Tracks

To make Track ID 2 (English AC-3) the default audio track, disable the default flag on Track ID 1, and enable the default flag on Track ID 3 (English Subtitles):

mkvmerge -o output.mkv \
  --default-track-flag 1:no \
  --default-track-flag 2:yes \
  --default-track-flag 3:yes \
  input.mkv

3. Automation Scripts

Bash Script (Linux / macOS)

This script iterates through all .mkv files in a directory, applies the specified track flags, and writes the modified files to an output directory.

#!/usr/bin/env bash

mkdir -p ./processed

for file in *.mkv; do
  [ -e "$file" ] || continue
  
  echo "Processing: $file"
  
  mkvmerge -o "./processed/$file" \
    --default-track-flag 1:no \
    --default-track-flag 2:yes \
    --default-track-flag 3:yes \
    "$file"
done

echo "Batch processing complete."

PowerShell Script (Windows)

New-Item -ItemType Directory -Force -Path .\processed

Get-ChildItem -Filter *.mkv | ForEach-Object {
    $inputFile = $_.FullName
    $outputFile = Join-Path -Path ".\processed" -ChildPath $_.Name
    
    Write-Host "Processing: $($_.Name)"
    
    & mkvmerge -o $outputFile `
      --default-track-flag 1:no `
      --default-track-flag 2:yes `
      --default-track-flag 3:yes `
      $inputFile
}

Write-Host "Batch processing complete."

4. In-Place Flag Modification Alternative (mkvpropedit)

If you want to modify default flags without remuxing the entire file to save time and disk space, use mkvpropedit (included with MKVToolNix):

mkvpropedit input.mkv \
  --edit track:a1 --set flag-default=0 \
  --edit track:a2 --set flag-default=1 \
  --edit track:s1 --set flag-default=1

Here, track:a1 targets the first audio track, track:a2 the second audio track, and track:s1 the first subtitle track.
