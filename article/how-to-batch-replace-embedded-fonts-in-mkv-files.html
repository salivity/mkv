How to Batch Replace Embedded Fonts in MKV Files

Managing embedded fonts across multiple Matroska (MKV) video files can be tedious if done manually one file at a time. The most reliable and efficient way to batch replace embedded font attachments across an entire library is by using MKVToolNix tools—specifically mkvpropedit—either paired with a dedicated graphical batch tool like JMkvpropedit or automated through custom shell and PowerShell scripts. These tools allow you to strip outdated or unwanted fonts and inject new ones directly into the file headers without re-encoding or remuxing the underlying audio and video streams.

Top Software Solutions for Batch Font Replacement

1. MKVToolNix (mkvpropedit Command-Line Tool)

MKVToolNix is the definitive open-source suite for working with MKV containers. While the primary GUI (mkvtoolnix-gui) excels at single-file muxing, its included command-line utility, mkvpropedit, allows in-place modification of attachments without recreating the file.

  • How It Works: You can delete all existing attachments or target specific font MIME types (such as application/x-truetype-font or font/sfnt) and attach replacement .ttf or .otf files.
  • Advantage: Fast, lightweight, and modifies files in place in seconds.

2. JMkvpropedit

JMkvpropedit is a graphical user interface wrapper built specifically for mkvpropedit. It allows users who prefer not to use the command line to apply batch operations across hundreds of files at once.

  • How It Works: Drag and drop an entire folder of MKV files into the interface, navigate to the Attachments tab, configure it to remove existing font attachments, and queue the new font files to be added.
  • Advantage: Offers a clean, visual interface with drag-and-drop batch processing functionality.

3. MKVBatchMultiplex

MKVBatchMultiplex is another GUI-based automation tool for MKVToolNix. It allows you to create a template settings file in MKVToolNix GUI—including new font tracks and attachment rules—and apply that template automatically across a queue of MKV files.

How to Automate Font Replacement with a Batch Script

Because mkvpropedit modifies metadata directly, scripting is the fastest method to batch process files.

Windows PowerShell Script

Run the following script in the folder containing your .mkv files and new fonts:

# Define the path to your new fonts folder
$NewFonts = Get-ChildItem -Path ".\new_fonts\" -Filter *.ttf

Get-ChildItem -Filter *.mkv | ForEach-Object {
    $mkv = $_.FullName
    
    # Remove all existing attachments
    & "mkvpropedit" "$mkv" --delete-attachment "mime-type:font/ttf" --delete-attachment "mime-type:application/x-truetype-font" --delete-attachment "mime-type:application/vnd.ms-opentype"

    # Add each new font
    foreach ($font in $NewFonts) {
        & "mkvpropedit" "$mkv" --add-attachment "$($font.FullName)"
    }
}

Linux / macOS Bash Script

#!/bin/bash
for file in *.mkv; do
    # Remove existing font attachments
    mkvpropedit "$file" --delete-attachment "mime-type:application/x-truetype-font" --delete-attachment "mime-type:font/ttf"

    # Attach all new fonts from a fonts directory
    for font in ./new_fonts/*.ttf; do
        mkvpropedit "$file" --add-attachment "$font"
    done
done

Using these methods ensures that the subtitle rendering styles match your updated font preferences across entire television seasons or movie collections in a matter of seconds.
