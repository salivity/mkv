How MKV Identifies Hearing Impaired Tracks

The Matroska (MKV) multimedia container identifies tracks designed for hearing-impaired accessibility primarily through a dedicated metadata element called FlagHearingImpaired. Alongside standard track naming conventions and language tagging, this built-in Extensible Binary Meta Language (EBML) flag allows modern media players to automatically recognize, categorize, and display subtitles for the deaf and hard of hearing (SDH) or enhanced dialogue audio streams.

The FlagHearingImpaired EBML Element

Matroska uses EBML to organize track information within the TrackEntry section of an MKV file. To identify accessibility features, the Matroska specification defines a specific boolean element:

  • Element Name: FlagHearingImpaired
  • EBML ID: 0x55B9
  • Type: Unsigned Integer / Boolean
  • Default Value: 0 (False)

When set to 1 (True), this flag explicitly signals to the demuxer and media player that the track contains content tailored for the hearing impaired.

Application to Subtitles and Audio

The hearing-impaired flag can be applied to different types of media streams within the MKV container:

  • Subtitle Tracks (SDH): Applied to subtitle streams to indicate that they include not only spoken dialogue but also sound effects, speaker identification, and ambient audio descriptions.
  • Audio Tracks: Applied to specialized audio mixes, such as clear voice or high-dialogue-enhancement streams designed to make speech more intelligible for individuals with hearing loss.

Additional Track Flags and Metadata

While FlagHearingImpaired is the primary standardized method, MKV containers also use surrounding metadata to provide complete context:

  • Language Tags (Language / LanguageIETF): Identifies the language of the track using ISO 639-2 codes or BCP 47 language tags.
  • Track Name (Name): Historically, and for legacy players that do not parse the FlagHearingImpaired element, creators often add text descriptors to the track title, such as "English (SDH)" or "English [CC]".
  • Related Accessibility Flags: Matroska includes companion flags such as FlagVisualImpaired (0x55BA) for audio descriptions and FlagDescriptions (0x55BB) for textual descriptions of video content.

How Media Players Use This Information

When an MKV file is opened, modern playback software (such as VLC, mpv, or Kodi) parses the TrackEntry elements. If the user has enabled accessibility preferences in the player settings, the player reads FlagHearingImpaired to automatically select the appropriate SDH subtitle track or present clear visual indicators (like an "SDH" badge) in the track selection menu.
