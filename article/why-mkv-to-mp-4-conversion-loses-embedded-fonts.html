Why MKV to MP4 Conversion Loses Embedded Fonts

Converting video files from Matroska (MKV) to MP4 often results in the loss of custom subtitle styling and embedded fonts. This issue is primarily caused by fundamental differences in container specifications, incompatible subtitle formats between the two containers, and the default stream-handling behavior of transcoding software.

Container Architecture Differences

The Matroska (MKV) container was designed with an open and flexible specification that natively supports arbitrary binary attachments. It allows creators to embed TrueType (.ttf) and OpenType (.otf) font files directly alongside video, audio, and subtitle tracks. In contrast, the MP4 container (based on the ISO Base Media File Format) is strictly standardized and does not include a universal mechanism for carrying arbitrary font attachments intended for soft subtitle rendering.

Subtitle Format Incompatibilities

Embedded fonts in MKV files are almost exclusively paired with Advanced SubStation Alpha (ASS/SSA) subtitle tracks. ASS scripts rely on specific font families to position, scale, and style text accurately. When transcoders convert a file to MP4, they cannot retain the native ASS stream because standard MP4 players typically only support basic text formats like mov_text (3GPP Timed Text) or WebVTT. During this conversion, rich styling instructions and links to embedded font assets are stripped down to raw, unstyled text.

Transcoder Multiplexing Limitations

When transcoders like FFmpeg, HandBrake, or consumer conversion tools process an MKV file, they identify embedded fonts as individual attachment streams (e.g., codec_type: attachment). Because the standard MP4 multiplexer (muxer) does not recognize or permit these attachment streams, the transcoder must drop them to generate a valid, standard-compliant MP4 file. Unless the transcoder is explicitly instructed to "burn" (hardcode) the styled subtitles directly into the video pixels, the styling and font metadata are omitted entirely from the final output.
