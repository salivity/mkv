Can MKV Store 192kHz 24-Bit Audio Streams?

The Matroska (MKV) container format fully supports audio streams with a 192 kHz sample rate and 24-bit depth. Because MKV is designed to be an open, highly extensible multimedia container, it imposes virtually no arbitrary restrictions on audio fidelity. This article details how MKV handles high-resolution audio, which codecs support these specifications within the container, and the technical requirements needed for proper playback.

How the Matroska Container Handles High-Resolution Audio

The MKV specification stores audio technical parameters as native metadata elements inside each audio track's header:

  • SamplingFrequency: Stored as a floating-point number, allowing standard high-resolution sample rates such as 88.2 kHz, 96 kHz, 176.4 kHz, 192 kHz, and beyond.
  • BitDepth: Stored as an unsigned integer, easily accommodating 16-bit, 24-bit, and 32-bit audio streams.

Because the container acts strictly as an envelope, it does not compress, alter, or resample the underlying audio data.

Supported 192 kHz / 24-Bit Codecs in MKV

You can encapsulate various lossless and uncompressed formats inside MKV that natively support 192 kHz / 24-bit audio:

  • FLAC (Free Lossless Audio Codec): Natively supports up to 655.35 kHz and up to 32-bit depth. A 192 kHz / 24-bit FLAC stream inside an MKV is standard and widely supported.
  • Linear PCM (LPCM / WAV): Raw, uncompressed high-resolution PCM can be multiplexed directly into an MKV file without loss of quality.
  • Dolby TrueHD: Supports lossless multichannel and stereo audio up to 192 kHz and 24 bits, commonly extracted from Blu-ray sources and stored in MKV.
  • DTS-HD Master Audio: Capable of delivering bit-for-bit lossless audio at 192 kHz / 24-bit for stereo and 96 kHz / 24-bit for multi-channel configurations inside MKV.
  • ALAC (Apple Lossless): Supports up to 384 kHz and 32-bit audio and can be packed into an MKV file.

Playback and Hardware Requirements

While the MKV file can store 192 kHz / 24-bit audio without issues, reproducing the audio at its native resolution requires a compatible hardware and software chain:

  1. Media Player: Modern players like VLC, mpv, MPC-HC, or Foobar2000 (with the Matroska plugin) can demux and decode high-resolution streams from MKV containers.
  2. Audio Drivers and Output Mode: To prevent the operating system from downsampling the audio, use exclusive output modes such as WASAPI Exclusive or ASIO on Windows, CoreAudio on macOS, or ALSA/Bit-Perfect output on Linux.
  3. Digital-to-Analog Converter (DAC): The playback device or external USB DAC must have hardware support for decoding 192 kHz sampling rates at 24-bit depth.
