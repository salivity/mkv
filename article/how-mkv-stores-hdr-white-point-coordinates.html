How MKV Stores HDR White Point Coordinates

The Matroska (MKV) container format stores High Dynamic Range (HDR) mastering display white point chromaticity coordinates natively within its track headers using Extensible Binary Meta Language (EBML) elements. Defined as part of the SMPTE ST 2086 standard for mastering display color volume metadata, these coordinates are stored as floating-point values under the video track's color configuration, allowing media players and displays to accurately reconstruct the color temperature and tone-mapping intended during the mastering process.

In the MKV specification, video colorimetry information is structured hierarchically within the track headers. The path to the white point chromaticity coordinates follows this structure:

Segment ➔ Tracks ➔ TrackEntry ➔ Video ➔ Colour ➔ MasteringMetadata

Inside the MasteringMetadata container element, two dedicated EBML elements define the white point coordinates in the CIE 1931 color space (\(xy\) chromaticity coordinates):

  • WhitePointChromaticityX (Element ID: 0x55DA): Stores the \(x\) coordinate of the white point as a standardized IEEE 754 floating-point number.
  • WhitePointChromaticityY (Element ID: 0x55DB): Stores the \(y\) coordinate of the white point as a standardized IEEE 754 floating-point number.

For typical HDR10 content mastered using the standard D65 white point, the WhitePointChromaticityX element contains a value of approximately 0.3127, and WhitePointChromaticityY contains approximately 0.3290.

While raw video bitstreams (such as HEVC or AV1) can also carry this data internally via Supplemental Enhancement Information (SEI) messages or sequence headers, storing these parameters at the MKV container level allows demuxers and hardware decoders to access display mastering parameters instantly without parsing the underlying video stream. If both container-level and bitstream-level metadata are present, rendering pipelines typically prioritize bitstream data or verify that the container-level coordinates match the stream metadata for consistent HDR playback.
