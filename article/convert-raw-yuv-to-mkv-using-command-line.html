Convert Raw YUV to MKV Using Command Line

It is entirely possible to generate an MKV (Matroska) file directly from raw YUV video frames using command-line tools like FFmpeg. Because raw YUV data contains pure uncompressed pixel information without any container headers or metadata, the conversion tool cannot automatically detect video properties. To successfully create an MKV file, you must explicitly supply the video dimensions, frame rate, and pixel format through the command-line interface.

Understanding the Raw YUV Input Requirements

Raw YUV files lack headers describing the stream. When working with command-line tools, you must define:

  • Pixel Format (-pix_fmt): Defines the chroma subsampling (e.g., yuv420p, yuv422p, yuv444p).
  • Resolution (-s or -video_size): The exact width and height of the video in pixels (e.g., 1920x1080).
  • Framerate (-r or -framerate): The playback speed in frames per second (e.g., 30, 60, 24).
  • Input Format (-f rawvideo): Informs the utility that the incoming file is an uncompressed raw stream.

Method 1: Wrapping Raw YUV into MKV Without Re-encoding

If your goal is to store the uncompressed YUV stream directly inside the MKV container without any quality loss or compression overhead, use the stream copy option:

ffmpeg -f rawvideo -pix_fmt yuv420p -s 1920x1080 -r 30 -i input.yuv -c:v copy output.mkv

In this command:

  • -c:v copy instructs FFmpeg to copy the raw frames directly into the MKV container without running a compression codec.
  • The resulting MKV file contains the raw video payload alongside standard playback metadata.

Method 2: Encoding Raw YUV to MKV Using a Video Codec

Raw video files are exceptionally large. To reduce file size while encapsulating the video in an MKV container, you can compress the stream using codecs like H.264 (AVC), H.265 (HEVC), or AV1:

ffmpeg -f rawvideo -pix_fmt yuv420p -s 1920x1080 -r 30 -i input.yuv -c:v libx264 -crf 18 output.mkv

Key options used here:

  • -c:v libx264: Uses the x264 encoder to compress the frames.
  • -crf 18: Sets the Constant Rate Factor for visually lossless quality.

Handling 10-bit and Other Chroma Formats

If the raw data uses higher bit depths or alternative color spaces (such as 10-bit yuv420p10le), update the -pix_fmt flag accordingly:

ffmpeg -f rawvideo -pix_fmt yuv420p10le -s 3840x2160 -r 60 -i input.yuv -c:v libx265 -crf 20 output.mkv

Using these straightforward FFmpeg commands allows you to process any raw YUV stream directly into a standard, playable MKV container from the terminal.
