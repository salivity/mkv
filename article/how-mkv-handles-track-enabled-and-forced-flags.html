How MKV Handles Track Enabled and Forced Flags

In the Matroska (MKV) container format, track selection and playback behaviors are governed by header metadata, primarily through the FlagEnabled (Track Enabled) and FlagForced (Track Forced) boolean flags. These binary values instruct media players whether a specific video, audio, or subtitle stream is usable during playback and whether it must be rendered automatically to provide critical contextual information, such as translations for foreign-language dialogue or on-screen text.

The Track Enabled Flag (FlagEnabled)

The FlagEnabled element (EBML ID 0xB9) is a boolean flag that defines whether a track is active and available for playback.

  • Default Value: 1 (True / Enabled)
  • Behavior when set to 1 (True): The demuxer and media player treat the track as active. It appears in track selection menus and is eligible for automatic or manual selection by the user.
  • Behavior when set to 0 (False): The track is marked as disabled. Compliant media players will completely hide or ignore the track, excluding it from standard track selection menus and preventing it from being selected during normal playback.

This flag is useful for multiplexed files containing alternative cuts, commentary tracks, or secondary streams that should remain dormant unless a specialized application or specific demuxing configuration explicitly requests them.

The Track Forced Flag (FlagForced)

The FlagForced element (EBML ID 0x55AA) indicates that a track contains essential information that must be presented to the viewer, regardless of their general playback preferences. While it can technically be applied to any track type, it is most commonly used for subtitle tracks.

  • Default Value: 0 (False / Not Forced)
  • Behavior when set to 1 (True): Tells the player that the content is mandatory for proper comprehension. For subtitle tracks, this typically contains translations for foreign-language scenes, narrative text, or signs within a movie where the main audio is in the viewer's native language.
  • Behavior when set to 0 (False): The track is treated as standard optional content (such as a full dialogue subtitle track) and will only be displayed if selected manually or triggered by the user's default language settings.

When a media player loads an MKV file, a forced subtitle track matching the language of the active audio stream is designed to display automatically, even if the user has subtitles turned off globally.

How Players Process Flag Priority

Compliant media players evaluate MKV track flags in a hierarchical manner:

  1. State Evaluation: The player checks FlagEnabled. If FlagEnabled=0, the track is discarded from standard playback logic, rendering any other flag on that track irrelevant.
  2. Forced Content Check: If FlagEnabled=1 and FlagForced=1, the player matches the track's language code against the active audio stream. If the languages align, the player activates the forced track automatically.
  3. Default Fallback: If no forced track applies, the player references FlagDefault alongside the user's configured language and subtitle preferences to determine which stream to play.
