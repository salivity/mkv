Batch Extract Subtitles From MKV Command Line

Demuxing subtitle tracks from multiple MKV files in bulk saves time and simplifies media library management. The most effective command-line tools for automated subtitle extraction are MKVToolNix (specifically mkvextract) and FFmpeg. By combining these utilities with simple shell scripts or batch loops, you can automatically extract subtitle streams across entire directories without manual processing.

1. MKVToolNix (mkvextract)

MKVToolNix is the standard software suite for working with the Matroska container format. Its dedicated extraction component, mkvextract, allows you to demux specific subtitle tracks cleanly.

To identify track IDs in an MKV file, use mkvmerge:

mkvmerge -J "input.mkv"

Once you know the subtitle track ID (for example, track ID 2), you can batch process an entire folder.

Bash (Linux/macOS):

for file in *.mkv; do
    mkvextract tracks "$file" 2:"${file%.mkv}.srt"
done

PowerShell (Windows):

Get-ChildItem -Filter *.mkv | ForEach-Object {
    & mkvextract tracks $_.FullName "2:$($_.BaseName).srt"
}

2. FFmpeg

FFmpeg is a versatile multimedia framework that handles conversion, stream copying, and demuxing. Unlike mkvextract, FFmpeg allows you to target subtitle streams by type rather than container-specific track IDs using stream mapping (-map 0:s).

To extract the first subtitle stream from all MKV files in a directory:

Bash (Linux/macOS):

for file in *.mkv; do
    ffmpeg -i "$file" -map 0:s:0 -c:s copy "${file%.mkv}.srt"
done

Windows Command Prompt (CMD):

for %F in (*.mkv) do ffmpeg -i "%F" -map 0:s:0 -c:s copy "%~nF.srt"

PowerShell (Windows):

Get-ChildItem -Filter *.mkv | ForEach-Object {
    ffmpeg -i $_.FullName -map 0:s:0 -c:s copy "$($_.BaseName).srt"
}

To extract all subtitle streams simultaneously into individual files, map each stream or specify the desired language tag (e.g., -map 0:s:m:language:eng).

3. Python-Based CLI Wrappers

If you require conditional logic—such as filtering by specific languages or dynamically detecting track numbers—a Python script utilizing subprocess with ffmpeg or mkvextract provides advanced automation.

import os
import subprocess
import glob

for mkv_file in glob.glob("*.mkv"):
    base_name = os.path.splitext(mkv_file)[0]
    cmd = [
        "ffmpeg", "-i", mkv_file,
        "-map", "0:s:0",
        "-c:s", "copy",
        f"{base_name}.srt"
    ]
    subprocess.run(cmd)

Tool Comparison

  • MKVToolNix (mkvextract): Best for preserving native Matroska track specifications without re-encoding, ideal when track structures are consistent.
  • FFmpeg: Best for dynamic extraction using metadata tags (like language or stream index) and automatic container format adaptation.
