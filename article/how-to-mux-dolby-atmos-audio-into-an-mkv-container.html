How to Mux Dolby Atmos Audio into an MKV Container

Muxing Dolby Atmos audio into an MKV (Matroska) container allows you to combine high-definition video with immersive, object-based surround sound in a single file without losing quality. This guide provides a straightforward, step-by-step walkthrough of the entire multiplexing process using MKVToolNix, the standard tool for managing MKV files, covering both lossless TrueHD and lossy Dolby Digital Plus Atmos tracks.

Prerequisites

To complete the process, you need:

  • MKVToolNix: The free, open-source software suite designed for modifying and multiplexing MKV files.
  • Video Source: Your raw video file (e.g., .mkv, .mp4, .hevc, .264).
  • Dolby Atmos Audio Track: The extracted audio stream, typically in .thd (Dolby TrueHD with Atmos) or .eac3 / .ddp (Dolby Digital Plus with Atmos).

Step 1: Open the Multiplexer in MKVToolNix

  1. Launch MKVToolNix GUI.
  2. Navigate to the Multiplexer tool from the left-hand navigation pane.

Step 2: Add Source Files

  1. Drag and drop your video file and your Dolby Atmos audio file into the Source files box.
  2. Alternatively, right-click inside the Source files window and select Add files to browse and select your video and audio tracks.

Step 3: Configure Tracks and Metadata

Once the files are added, all available tracks (video, audio, subtitles, chapters) will appear in the Tracks, chapters and tags pane.

  1. Select the Atmos Track: Click on the audio track you wish to configure.
  2. Set the Language: Under the Properties panel on the right, set the correct language tag (e.g., English (eng)).
  3. Set the Track Name: Label the track descriptively (e.g., Dolby Atmos / TrueHD 7.1 or Dolby Atmos / EAC-3 5.1).
  4. Set Default/Forced Flags:
    • Set "Default track" flag to Yes if you want this track to play automatically.
    • Set "Forced display" flag to No (unless specifically required).
  5. Adjust Sync (Optional): If the audio requires a timing offset, navigate to the Timestamp and subtitle properties section and enter the delay in milliseconds in the Delay (in ms) field.

Step 4: Arrange Track Order

Use the up and down arrows on the right side of the tracks list to position your tracks logically. The standard order is:

  1. Video track
  2. Primary audio track (Dolby Atmos)
  3. Secondary audio tracks (commentary, stereo downmix, etc.)
  4. Subtitles

Step 5: Choose Destination and Start Muxing

  1. In the Destination file field at the bottom, set the output path and filename for the final MKV file.
  2. Click the Start multiplexing button at the bottom of the interface.
  3. MKVToolNix will process the streams and create the new MKV container without re-encoding, preserving full audio and video fidelity.

Verifying the Output

To verify that the Atmos metadata is properly preserved:

  • Open the completed .mkv file in MediaInfo and check the audio section for the Dolby Atmos profile under commercial name or format details.
  • Play the file through an Atmos-capable AV Receiver or soundbar using a passthrough-capable media player (such as Kodi, Infuse, MPC-HC, or a compatible hardware player) to confirm the Atmos indicator triggers.
