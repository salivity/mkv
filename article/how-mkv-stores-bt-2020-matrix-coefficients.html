How MKV Stores BT.2020 Matrix Coefficients

The Matroska (MKV) multimedia container stores matrix coefficients for BT.2020 wide color gamut video as integer-based metadata within its structural video track headers. Specifically, MKV utilizes the Extensible Binary Meta Language (EBML) Colour master element to host the MatrixCoefficients tag, mapping standardized values from ITU-T H.273 and ISO/IEC 23001-8. This container-level signaling ensures that demuxers and video renderers can accurately identify and convert YCbCr color representations to RGB across the wide BT.2020 color gamut, even prior to parsing the underlying video bitstream.

Matroska EBML Hierarchy for Color Metadata

Matroska structures all file metadata using hierarchical EBML elements. Video color configuration is placed inside the track definition rather than within the individual data clusters. The path for color metadata follows this hierarchy:

  • Segment (0x18538067)
    • Tracks (0x1654AE6B)
      • TrackEntry (0xAE)
        • Video (0xE0)
          • Colour (0x55B0)
            • MatrixCoefficients (0x55B1)

The Colour element acts as a container for all colorimetry settings, including color primaries, transfer characteristics, and matrix coefficients.

The MatrixCoefficients Element

The MatrixCoefficients element (EBML ID 0x55B1) is stored as an unsigned integer (uinteger). Matroska aligns its value definitions directly with the Coding-Independent Code Points (CICP) specified by ITU-T H.273 / ISO/IEC 23091-2.

For BT.2020 wide color gamut content, the MatrixCoefficients element uses one of two standardized numerical values:

  • Value 9 (BT.2020 Non-Constant Luminance): Indicates the standard ITU-R BT.2020 non-constant luminance (NCL) system. This is the predominant matrix used for 4K Ultra HD Blu-ray, HDR10, and modern wide color gamut broadcast and streaming pipelines.
  • Value 10 (BT.2020 Constant Luminance): Indicates the ITU-R BT.2020 constant luminance (CL) system.

When an MKV file contains a value of 9, the rendering pipeline uses the following derivation equations to convert normalized linear RGB components into \(Y'C'_BC'_R\):

\[Y' = 0.2627R' + 0.6780G' + 0.0593B'\] \[C'_B = \frac{B' - Y'}{1.8814}\] \[C'_R = \frac{R' - Y'}{1.4746}\]

Container vs. Codec Bitstream Signaling

Video codecs such as HEVC (H.265), AV1, and AVC (H.264) often embed matrix coefficients directly within their elementary bitstreams (for example, inside the Video Usability Information/VUI block in HEVC). MKV’s container-level MatrixCoefficients element works alongside this stream data:

  • Pre-decode Configuration: Media players, splitters, and hardware scalers can configure the display rendering pipeline before decoding the video stream.
  • Override and Fallback: If the elementary stream lacks color metadata or contains incorrect flags, container-aware decoders and renderers can rely on the MKV MatrixCoefficients element to enforce the correct color conversion matrix.
