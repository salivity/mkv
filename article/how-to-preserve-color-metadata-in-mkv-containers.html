How to Preserve Color Metadata in MKV Containers

Preserving color primaries and matrix coefficients metadata inside a Matroska (MKV) container ensures that high dynamic range (HDR) and wide color gamut (WCG) video streams render accurately across diverse media players. When these signaling parameters are missing or stripped during remuxing or encoding, playback devices often default to standard Rec. 709 color spaces, leading to washed-out or oversaturated colors. This guide explains how to retain or inject this crucial color metadata at both the container level and the video bitstream level.

Understanding Color Metadata in MKV

Color metadata exists in two distinct layers of a digital video file:

  1. Bitstream Level (VUI): Video Usability Information embedded directly into the video elementary stream (H.264, HEVC, AV1, or VP9).
  2. Container Level (Matroska Headers): EBML header elements specifically allocated under the MKV Colour element, including ColourPrimaries, MatrixCoefficients, and TransferCharacteristics.

For maximum compatibility, both layers should contain matching metadata values (e.g., BT.2020 or BT.709).

Method 1: Injecting or Editing Metadata Using MKVToolNix

MKVToolNix provides the most reliable way to modify container-level color metadata without re-encoding the video track.

Using mkvpropedit (Command Line)

You can directly modify existing MKV files in place using the mkvpropedit utility.

To set the color parameters for HDR10 (BT.2020 / SMPTE ST 2084 / BT.2020 non-constant luminance):

mkvpropedit "input.mkv" --edit track:v1 \
  --set colour-primaries=9 \
  --set colour-transfer-characteristics=16 \
  --set colour-matrix-coefficients=9 \
  --set colour-range=1

Common standard integer values:

  • BT.709: Primaries = 1, Transfer = 1, Matrix = 1
  • BT.2020 (HDR10/PQ): Primaries = 9, Transfer = 16, Matrix = 9
  • BT.2020 (HLG): Primaries = 9, Transfer = 18, Matrix = 9

Using MKVToolNix GUI

  1. Open the MKV file in MKVToolNix GUI (or use the Header Editor).
  2. Select the Video track.
  3. Locate the Color / Mastering metadata section.
  4. Set the dropdown fields for:
    • Colour primaries (e.g., ITU-R BT.2020)
    • Transfer characteristics (e.g., SMPTE ST 2084 or ITU-R BT.709)
    • Matrix coefficients (e.g., ITU-R BT.2020 non-constant luminance)
  5. Click Start multiplexing or Save if using the Header Editor.

Method 2: Setting Metadata During FFmpeg Remuxing

When remuxing streams from MP4, TS, or another MKV into a new MKV container, FFmpeg can write metadata tags to both the stream and the container headers.

Remuxing Without Re-encoding (-c:v copy)

ffmpeg -i input.mp4 -c copy \
  -color_primaries bt2020 \
  -color_trc smpte2084 \
  -colorspace bt2020nc \
  -color_range tv \
  output.mkv
  • -color_primaries: Sets the chromaticity coordinates of the source color primaries.
  • -color_trc: Defines the opto-electronic transfer characteristics.
  • -colorspace: Sets the matrix coefficients used for deriving luma and chroma signals.

Method 3: Preserving Metadata During Video Encoding

If re-encoding the video before packing it into MKV, configure the encoder to write VUI parameters directly into the elementary bitstream.

For x265 (HEVC):

Pass the relevant VUI parameters to the encoder:

ffmpeg -i input.mov -c:v libx265 -crf 18 \
  -x265-params "colorprim=bt2020:transfer=smpte2084:colormatrix=bt2020nc:range=limited" \
  output.mkv

For x264 (AVC):

ffmpeg -i input.mov -c:v libx264 -crf 18 \
  -x264-params "colorprim=bt709:transfer=bt709:colormatrix=bt709" \
  output.mkv

Verifying the MKV Color Metadata

To ensure the parameters are correctly embedded, inspect the resulting MKV file using mediainfo:

mediainfo output.mkv

Look for the following fields under the Video section:

  • Color primaries
  • Transfer characteristics
  • Matrix coefficients
  • Color range

If these fields match your target specification, the MKV container and its underlying stream are correctly configured for color-accurate decoding and playback.
