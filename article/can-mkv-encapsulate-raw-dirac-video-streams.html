Can MKV Encapsulate Raw Dirac Video Streams?

The Matroska (MKV) container format fully supports the encapsulation of raw Dirac video streams. Matroska was designed to be universally extensible, allowing it to store virtually any multimedia codec, including Dirac. Through the standardized V_DIRAC Codec ID, software muxers can package raw Dirac sequence units directly into Matroska tracks without requiring an intermediate container format like Ogg.

The Matroska Dirac Specification

Matroska defines specific mapping rules for storing Dirac video data. The codec identifier used in the Matroska track headers is V_DIRAC.

When encapsulating Dirac into an MKV file:

  • CodecPrivate Element: The CodecPrivate element in the Matroska header can store global sequence header information, ensuring decoders understand parameters such as frame dimensions, chroma format, and frame rate before decoding frames.
  • Block Data: Each MKV Block typically carries one Dirac frame (Access Unit) or parse unit, starting with the Dirac parse info prefix. This 13-byte header indicates the type of data being transmitted (e.g., sequence header, picture, or end of sequence).

How Encapsulation Works in Practice

Raw Dirac video typically exists as an elementary bitstream (.drc or raw byte streams). During the multiplexing process, the muxer parses the bitstream to identify frame boundaries and timestamps.

  1. Header Extraction: The initial sequence configuration is parsed to set up container-level metadata, such as pixel resolution and display aspect ratio.
  2. Packetization: Elementary stream data units are placed directly into Matroska SimpleBlock or BlockGroup structures.
  3. Timecode Assignment: Because raw streams might lack native container-level timestamps, the muxer assigns explicit presentation timecodes to each frame within the MKV clusters based on the sequence frame rate.

Tooling and Compatibility

Standard multimedia tools support the creation and playback of Dirac streams in MKV containers:

  • FFmpeg: Allows direct remuxing of raw Dirac streams into MKV containers using the command ffmpeg -i input.drc -c copy output.mkv.
  • MKVToolNix: Earlier versions and libraries utilizing standard Matroska specifications natively recognize the V_DIRAC codec identifier.
  • VLC and Libavcodec-based Players: Can demux and decode Dirac video stored inside MKV files natively.

While modern royalty-free formats like AV1 and VP9 have largely superseded Dirac for consumer distribution, MKV remains one of the few flexible container formats capable of encapsulating raw Dirac bitstreams for preservation, testing, and legacy broadcast workflows.
