How to Check MKV Packet Corruption Without Decoding

Inspecting a Matroska (MKV) video file for packet and container corruption does not require a slow, resource-heavy full video decode. By utilizing stream-level analysis tools such as FFmpeg, FFprobe, and mkvalidator, you can quickly scan the underlying EBML container and multiplexed packet headers for missing data, broken timestamps, and corrupted payloads at pure disk-read speeds.

Method 1: Fast Packet Demuxing with FFmpeg

The fastest way to verify packet continuity across all streams without decoding video frames is to run a null demux with stream copying in FFmpeg. This forces the demuxer to read every packet in the MKV container, reporting any packet header faults or truncation:

ffmpeg -v error -i input.mkv -c copy -f null -
  • -v error: Suppresses standard operational output and only prints stream/packet errors.
  • -c copy: Copies streams directly, bypassing video and audio decoders.
  • -f null -: Discards the output data so no new file is written to disk.

If the command completes with no terminal output, the container structure and packet boundaries are intact. Any packet-level issues, such as missing frames, damaged headers, or premature EOF (End of File), will be printed with corresponding timestamps.

Method 2: Detailed Packet Inspection with FFprobe

If you need to analyze individual packets to locate specific dropped frames or corrupted presentation timestamps (PTS/DTS), use FFprobe:

ffprobe -v error -show_packets -select_streams v:0 input.mkv > packets.log

This processes the stream sequentially and outputs packet metadata. If a corrupted packet halts processing or contains invalid data lengths, FFprobe outputs an error to stderr while logging the successfully parsed packets, allowing you to pinpoint the exact second where the failure occurs.

Method 3: Structural EBML Validation with mkvalidator

Corruption can also occur strictly within the Matroska container structure (such as malformed EBML elements, invalid cluster sizes, or broken seek tables) rather than the video codec bitstream. The mkvalidator command-line utility (part of the Matroska specification tools) performs structural verification:

mkvalidator input.mkv

mkvalidator parses all MKV elements down to the block level without touching codecs. It will flag:

  • Invalid or unaligned track headers.
  • Missing SimpleBlocks or damaged BlockGroups.
  • Desynchronized cluster timestamps.
