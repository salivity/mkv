How MKV Containers Identify Commentary Audio Tracks

The Matroska (MKV) container format identifies commentary audio tracks primarily through standardized Extensible Binary Meta Language (EBML) track headers, most notably the dedicated FlagCommentary element and descriptive TrackName metadata. By combining standardized track flags, language descriptors, and structural track properties, the container allows media players and demuxers to recognize and present commentary tracks accurately to users.

The Standard FlagCommentary Element

In modern Matroska specifications, a dedicated boolean element named FlagCommentary (EBML ID 0x55EE) is placed inside the TrackEntry master element. When set to 1 (true), it programmatically signals to media players that the audio track contains commentary (such as director, cast, or crew discussions) rather than standard primary or alternative dialogue. Setting it to 0 (false) indicates standard audio. This flag eliminates the need for software to parse arbitrary text strings to detect commentary.

The TrackName Element

Historically and in tandem with modern flags, MKV files use the Name or TrackName element (EBML ID 0x536E) to specify commentary tracks. This string field contains human-readable labels such as "Director's Commentary" or "Cast Commentary." While legacy software relies on parsing this string to identify track content, modern muxing tools typically write both the TrackName string and the FlagCommentary element to ensure broad compatibility.

Supporting Metadata and Properties

A commentary track is contextualized within the MKV container using several complementary EBML elements within the TrackEntry:

  • TrackType (EBML ID 0x83): Set to 2 to identify the stream as an audio track.
  • Language / LanguageIETF (EBML IDs 0x22B59C and 0x22B59D): Specifies the language code (such as ISO 639-2 or BCP 47) spoken in the commentary.
  • FlagDefault (EBML ID 0x88): Typically set to 0 (false) for commentary tracks, ensuring media players do not automatically play the commentary over the main feature audio on initial playback.
  • FlagOriginal (EBML ID 0x55E7): Distinguishes whether the track is in the original production language alongside the commentary flag.

When modern media players, transcoders, and tools like MKVToolNix or FFmpeg process an MKV file, they read the TrackEntry header to evaluate these combined tags. If FlagCommentary is active or a recognized commentary label is present in the TrackName, the audio stream is tagged accordingly in the player's track selection menu.
