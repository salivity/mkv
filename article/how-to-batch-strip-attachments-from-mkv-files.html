How to Batch Strip Attachments from MKV Files

MKV (Matroska) containers frequently bundle embedded attachments such as custom subtitle fonts, cover art, and extra metadata that needlessly inflate storage across large media libraries. Media processing tools batch-strip these embedded elements by remuxing the container or modifying its header structure directly without re-encoding the underlying video and audio tracks. This guide outlines the core mechanics behind attachment removal, the standard command-line tools used, and how to automate the process across multiple files simultaneously.

Why MKV Files Contain Embedded Attachments

The Matroska format allows arbitrary binary data to be embedded alongside media streams. The most common attachments include:

  • TrueType/OpenType Fonts (.ttf, .otf): Included to render styled Advanced SubStation Alpha (.ass) subtitles exactly as intended by the creator.
  • Cover Art and Poster Images (.jpg, .png): Metadata images used by media servers and software players.
  • XML/Text Metadata: Supplemental chapter data or production details.

When dealing with large TV show seasons or entire film libraries, redundant or oversized font attachments and multi-megabyte image files can accumulate into gigabytes of wasted storage space.

The Mechanism: In-Place Modification vs. Remuxing

Media processing tools handle attachment stripping in one of two ways:

  1. In-Place Header Editing (Propedit): The tool parses the MKV container, locates the attachment references in the track header and payload table, and deletes or unlinks them directly without rewriting the video or audio streams. This method is nearly instantaneous because the bulk media data is untouched on the disk.
  2. Container Remuxing (Stream Copying): The tool demultiplexes the input file, copies only the requested streams (video, audio, subtitles, chapters) into a new file, and drops the attachment tracks entirely. While slightly slower than in-place editing due to disk I/O, it produces a clean, defragmented container.

Because neither method decodes or compresses the audio and video streams, the process produces zero quality loss and completes at the maximum read/write speed of your storage device.

Core Tools for Batch-Stripping MKV Attachments

1. MKVToolNix (mkvpropedit and mkvmerge)

The official MKVToolNix suite provides the most reliable utilities for handling Matroska files.

  • mkvpropedit (Fastest, In-Place): It can target attachments and delete them directly.

    mkvpropedit "video.mkv" --delete-attachment 1

  • mkvmerge (Remuxing): The --no-attachments flag instructs the multiplexer to ignore all embedded files when creating a new output file.

    mkvmerge -o "output.mkv" --no-attachments "input.mkv"

2. FFmpeg

FFmpeg can strip attachments by utilizing stream mapping specifiers combined with stream copying (-c copy).

  • In FFmpeg syntax, attachments are classified as the t stream type (e.g., -map -0:t tells FFmpeg to exclude all attachment streams from the output).

    ffmpeg -i "input.mkv" -map 0 -map -0:t -c copy "output.mkv"

Automating Batch Processing

To strip attachments from dozens or hundreds of files at once, command-line tools can be wrapped in simple shell scripts.

Windows (PowerShell) Using mkvpropedit

This script iterates through a folder and wipes all attachments from every .mkv file in place:

Get-ChildItem -Filter *.mkv | ForEach-Object {
    mkvpropedit $_.FullName --delete-attachment "mime-type:application/x-truetype-font" --delete-attachment "mime-type:image/jpeg" --delete-attachment "mime-type:image/png"
}

Linux/macOS (Bash) Using mkvmerge

This script remuxes all .mkv files in a directory to a new cleaned folder while stripping attachments:

mkdir -p cleaned
for file in *.mkv; do
    mkvmerge -o "cleaned/$file" --no-attachments "$file"
done

Storage and Compatibility Considerations

  • Subtitle Display: Removing embedded font files will cause media players to fall back to default system fonts. If styled subtitles depend on specific typography, visual formatting may alter slightly during playback.
  • Disk Space Gains: Stripping attachments from a single movie may only save 5 to 50 MB, but across a 1,000-episode series or full media library, batch removal routinely recovers tens of gigabytes of disk space without altering media quality.
