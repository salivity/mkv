How to Split MKV by Time in MKVToolNix CLI

This article explains how to split Matroska (MKV) video files by time intervals using the mkvmerge command-line tool included with MKVToolNix. By utilizing the --split parameter, you can slice large videos into smaller segments by fixed durations, specific timestamps, or exact time ranges without re-encoding the underlying video and audio streams.

The Core Command: --split

MKVToolNix handles file splitting through the mkvmerge utility using the --split option. Splitting by time does not re-encode the media, meaning the process is fast and preserves original quality.

1. Split at Regular Time Intervals (Duration)

To split an MKV file into segments of a fixed length, use the duration: mode.

Syntax:

mkvmerge -o output_%03d.mkv --split duration:<HH:MM:SS.NNN|Xs> input.mkv
  • duration:00:10:00: Splits the file every 10 minutes.
  • duration:600s: Alternative notation specifying the interval in seconds.
  • output_%03d.mkv: Creates numbered output files (e.g., output_001.mkv, output_002.mkv).

Example:

mkvmerge -o split_part_%02d.mkv --split duration:00:15:00 input.mkv

This command cuts input.mkv into distinct files every 15 minutes.

2. Split at Specific Timestamps

If you need to cut the video at distinct points in time rather than equal intervals, use the timestamps: mode with comma-separated values.

Syntax:

mkvmerge -o output_%03d.mkv --split timestamps:<timestamp1,timestamp2,...> input.mkv

Example:

mkvmerge -o chapter_%02d.mkv --split timestamps:00:05:30,00:18:45,01:02:10 input.mkv

This command produces four files:

  1. Start to 00:05:30
  2. 00:05:30 to 00:18:45
  3. 00:18:45 to 01:02:10
  4. 01:02:10 to the end of the video

3. Extract Specific Time Ranges (Parts)

To keep only specific sections of a file and discard the rest, use the parts: mode.

Syntax:

mkvmerge -o output_%03d.mkv --split parts:<start1>-<end1>,<start2>-<end2> input.mkv
  • Using a comma creates separate output files for each range.
  • Using a plus sign (+) appends the parts together into a single continuous file (e.g., parts:00:01:00-00:05:00,+00:10:00-00:15:00).

Example:

mkvmerge -o clip_%02d.mkv --split parts:00:02:00-00:04:30,00:10:00-00:12:00 input.mkv

Important Considerations

  • Keyframes: mkvmerge splits video files at the nearest keyframe (I-frame) prior to or at the specified timestamp. To force splitting precisely at the requested frame even if it is not a keyframe, append the --split option with parts-frames: or ensure the file was encoded with frequent keyframe intervals.
  • Pattern Placeholders: Use %d or %02d / %03d in the output filename to control zero-padded numbering for the generated files.
