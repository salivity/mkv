Tools to Verify MKV File Integrity and Compliance

Matroska (MKV) is an open-standard, highly flexible multimedia container that wraps video, audio, subtitles, and metadata into an Extensible Binary Meta Language (EBML) structure. Because of this complexity, files can sometimes suffer from structural corruption, missing header elements, or non-compliance with the official Matroska specification. This guide outlines the most effective software tools and utilities available for verifying the structural integrity, stream consistency, and formal compliance of MKV files.

1. MediaConch

Developed by the MediaArea team, MediaConch is specifically designed for conformance checking and validation of Matroska files against the official specification and custom user-defined policies. It is widely used in digital preservation and professional archiving.

  • Specification Validation: Tests files directly against the Matroska specification to identify invalid EBML structures, bad syntax, or out-of-spec elements.
  • Custom Policies: Allows users to enforce specific technical requirements (e.g., verifying that a specific audio format, track layout, or aspect ratio is present).
  • Interfaces: Available as a Graphical User Interface (GUI), Command-Line Interface (CLI), and as a software development library (libmediaconch).

2. MKVToolNix (mkvinfo and mkvmerge)

MKVToolNix is the official, definitive suite for creating, modifying, and inspecting Matroska files. It includes dedicated command-line utilities capable of deeply analyzing the container layer.

  • mkvinfo: Parses the internal EBML tree and displays all elements, tracks, timecodes, and cluster data. Any parsing errors, malformed headers, or unreadable blocks are immediately flagged during scanning.
  • mkvmerge (Identification & Remuxing): Running mkvmerge -J input.mkv outputs the structural JSON data of the file. If severe structural corruption exists, mkvmerge will report structural warnings and read errors. Remuxing through mkvmerge can also serve as a functional test to see if all tracks and frames can be cleanly extracted and rewritten without error.

3. FFmpeg and FFprobe

While primarily a transcoding framework, FFmpeg is one of the most practical tools for checking both container structural integrity and the decoding validity of the underlying streams.

  • Full Stream Integrity Check: You can decode the entire container and its streams to null output to catch corrupt frames, missing index tables, or bad timecodes using the following command:

    ffmpeg -v error -i input.mkv -f null -

    If this command produces no output, the container and inner streams decoded without structural or decoding errors.

  • Packet and Stream Analysis (FFprobe): FFprobe inspects packet layouts, frame ordering, and timestamps to check for non-monotonic timecodes, packet loss, or corrupt intervals.

4. MediaInfo

Also created by MediaArea, MediaInfo is the standard tool for quick metadata analysis and container inspection.

  • Integrity Warnings: MediaInfo reads the entire header structure, tracks, and segment info. If a file is truncated, missing key indexes, or contains mismatched header properties, MediaInfo will often flag these inconsistencies or show incomplete metadata fields.
  • Quick Diagnostics: Ideal for a fast visual overview to ensure that expected tracks, codecs, language tags, and default track flags are correctly populated according to specification.

5. Matroska Diagnostics (ebml_validator and libebml)

For low-level EBML validation, developers and advanced users can utilize specialized EBML parsers derived from libebml and libmatroska.

  • EBML Schema Verification: These utilities validate that the byte stream conforms to the correct EBML data types (integers, strings, Master elements) and lengths defined in the Matroska schema.
  • Truncation Detection: Identifies incomplete elements at the end of files caused by interrupted downloads or incomplete file transfers.
