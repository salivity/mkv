Change MKV Track Language in FFmpeg Losslessly

This guide explains how to modify the language metadata of specific audio, video, or subtitle tracks in an MKV container using FFmpeg. By utilizing stream copying, FFmpeg can update the track language tags instantly without re-encoding the underlying media, ensuring zero quality loss.

The Basic Command Structure

To change language metadata losslessly, use the -c copy flag alongside the -metadata:s stream specifier and -map 0 to preserve all existing streams:

ffmpeg -i input.mkv -map 0 -c copy -metadata:s:a:0 language=eng output.mkv

Key Parameters Explained

  • -i input.mkv: Specifies the source file.
  • -map 0: Ensures that all streams (video, all audio tracks, subtitles, and attachments) from the input file are included in the output file. By default, FFmpeg selects only one stream of each type unless specified.
  • -c copy: Copies all streams directly without decoding or re-encoding, making the process lossless and extremely fast.
  • -metadata:s:[type]:[index] language=[code]: Sets the language property for the designated stream.
    • [type]: Stream type—a for audio, s for subtitles, or v for video.
    • [index]: The zero-based index of the stream within that specific type (e.g., a:0 is the first audio track, a:1 is the second audio track).
    • [code]: The 3-letter ISO 639-2 language code (e.g., eng for English, jpn for Japanese, spa for Spanish, fre or fra for French).

Common Examples

1. Change the First Audio Track Language

To set the first audio track to Japanese:

ffmpeg -i input.mkv -map 0 -c copy -metadata:s:a:0 language=jpn output.mkv

2. Change the First Subtitle Track Language

To set the first subtitle track to Spanish:

ffmpeg -i input.mkv -map 0 -c copy -metadata:s:s:0 language=spa output.mkv

3. Change Multiple Tracks at Once

To change the second audio track to English and the second subtitle track to French in a single command:

ffmpeg -i input.mkv -map 0 -c copy -metadata:s:a:1 language=eng -metadata:s:s:1 language=fre output.mkv

4. Add a Track Title Along with Language

To assign both a language code and a descriptive track title:

ffmpeg -i input.mkv -map 0 -c copy -metadata:s:a:0 language=eng -metadata:s:a:0 title="Director Commentary" output.mkv
