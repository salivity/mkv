Multiple Video Streams in MKV with Different Resolutions

The Matroska (MKV) container format natively supports storing multiple video streams featuring completely different resolutions, aspect ratios, frame rates, and codecs within a single file. Unlike more restrictive containers, MKV is designed to be highly flexible, allowing each video track to function as an independent data stream. This article covers how MKV handles multiple video streams of varying resolutions, common use cases for this feature, and playback compatibility.

How MKV Supports Multiple Video Tracks

The MKV container is built on EBML (Extensible Binary Meta Language), a binary equivalent of XML. This architecture treats every component of a media file—video, audio, subtitles, and metadata—as independent tracks.

The Matroska specification imposes no requirement that video tracks share the same properties. Within a single .mkv file:

  • Track 1 can be a 4K UHD (3840x2160) stream encoded in HEVC (H.265).
  • Track 2 can be a 1080p (1920x1080) stream encoded in AVC (H.264).
  • Track 3 can be a 480p (720x480) stream encoded in AV1.

Each stream contains its own header information defining its pixel dimensions, display aspect ratio, frame rate, and compression format.

Common Use Cases

Storing multiple video streams of varying resolutions in one MKV container is useful in several scenarios:

  • Multi-Device Archiving: A single master file can store a full-resolution 4K version alongside a lower-resolution 720p version optimized for low-power mobile devices.
  • Alternate Angles and Commentary: Multi-angle concert footage or sports broadcasts can feature a high-resolution primary camera feed alongside lower-resolution secondary angles or picture-in-picture director commentary.
  • Aspect Ratio Variations: Films with both theatrical (e.g., 2.39:1) and IMAX/open-matte (e.g., 1.78:1) presentations can include both video masters in a single package.

Media Player and Hardware Compatibility

While the MKV container fully supports multiple video streams with different resolutions, user playback depends on the media player software:

  • Desktop Players: Advanced software players such as VLC Media Player, MPV, and MPC-HC fully support switching between distinct video tracks on the fly via their video track menus.
  • Hardware and Smart TVs: Built-in media players on smart TVs, game consoles, and streaming set-top boxes typically default to the first video track (Track 1 or the track flagged as "Default") and often lack user interface options to toggle secondary video tracks.
  • Transcoding Servers: Media servers like Plex or Jellyfin may only present the primary video stream unless individual files are structured according to their specific multi-version naming guidelines.

Creating Multi-Stream MKV Files

Tools such as MKVToolNix (specifically the mkvmerge utility) or FFmpeg can multiplex distinct video files into a single MKV container without re-encoding:

ffmpeg -i video_4k.mp4 -i video_1080p.mp4 -map 0:v -map 1:v -c copy output.mkv

This command takes two separate source files of different resolutions and copies their raw video streams directly into a unified MKV container.
