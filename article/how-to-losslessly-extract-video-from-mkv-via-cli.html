How to Losslessly Extract Video from MKV via CLI

Extracting the primary video stream from a Matroska (MKV) container without re-encoding preserves full visual fidelity and finishes in seconds. This guide details how to use powerful command-line tools—primarily FFmpeg and MKVToolNix (mkvextract)—to demux and save the original, untouched video stream from any MKV file.

Method 1: Using FFmpeg (Recommended)

FFmpeg is the most versatile cross-platform tool for media manipulation. It achieves lossless extraction through stream copying, which extracts the compressed data packets directly without decoding or re-encoding.

1. Identify the Video Codec

Check the video format inside the MKV to choose the proper output extension:

ffprobe -v error -select_streams v:0 -show_entries stream=codec_name -of default=noprint_wrappers=1:nokey=1 input.mkv

Common codecs include h264, hevc (H.265), vp9, and av1.

2. Extract the Stream

Run the following command to isolate the first video track:

ffmpeg -i input.mkv -map 0:v:0 -c:v copy output.mp4
  • -i input.mkv: Specifies the source file.
  • -map 0:v:0: Selects the first video stream from the first input file (ignoring audio, subtitles, and secondary video tracks).
  • -c:v copy: Directs FFmpeg to copy the video codec stream bit-for-bit without re-encoding.
  • output.mp4: The target container. If extracting raw bitstreams instead of a container, use the appropriate raw extension (e.g., output.h264 or output.hevc).

Method 2: Using MKVToolNix (mkvextract)

mkvextract is a specialized tool tailored specifically for Matroska files, making it ideal for extracting raw elementary streams.

1. Identify the Track ID

Inspect the MKV structure to find the track ID of the video stream:

mkvmerge -i input.mkv

Look for output indicating the video track (usually Track ID 0).

2. Extract the Elementary Stream

Extract the video track using its ID:

mkvextract tracks input.mkv 0:video_stream.h264

Replace 0 with the correct Track ID and .h264 with the matching format extension (.hevc, .vp9, etc.).

Summary

  • Use FFmpeg when you want to extract the video into a new container format (like MP4 or MOV) losslessly via -c:v copy.
  • Use mkvextract when you need raw, standalone elementary video bitstreams directly from an MKV file.
