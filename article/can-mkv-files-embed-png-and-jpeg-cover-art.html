Can MKV Files Embed PNG and JPEG Cover Art?

The Matroska (MKV) container format fully supports embedding both PNG cover art and JPEG poster images within the same file simultaneously. Because Matroska is an extensible multimedia container, it allows users to attach arbitrary binary files directly into the file structure without affecting the video or audio streams. This article explains how MKV handles multiple image attachments, the standard naming conventions used for covers and posters, and how media players interpret these embedded files.

Matroska Attachment Architecture

MKV files do not restrict embedded graphics to a single image or format. The container features a dedicated attachment section where files are stored alongside their metadata, including:

  • File Name: The designated name of the image (e.g., cover.jpg, poster.png).
  • MIME Type: The media type declaration, such as image/jpeg or image/png.
  • Description: An optional text description defining the image role (e.g., "Front Cover", "Back Poster", or "Landscape Fanart").

Because each attachment is treated as an independent asset, you can attach any combination of JPEG and PNG files to a single MKV file without conflict.

Official Naming Conventions for Posters and Covers

To ensure media centers and software players recognize which image serves which purpose, the Matroska specification establishes standard naming rules for embedded artwork:

  • cover.jpg or cover.png: Main front cover (portrait orientation).
  • small_cover.jpg or small_cover.png: A thumbnail-sized version of the front cover.
  • cover_land.jpg or cover_land.png: Widescreen or landscape poster/backdrop.
  • small_cover_land.jpg or small_cover_land.png: Thumbnail version of the landscape artwork.

You can mix and match formats across these roles. For instance, you can use cover.png for high-resolution front cover art while using cover_land.jpg for a compressed landscape backdrop.

How to Embed Multiple Artwork Formats

Adding these images to an MKV file is typically done using tools like MKVToolNix (specifically mkvmerge or the MKVToolNix GUI):

  1. Open the MKV file in the multiplexer.
  2. Navigate to the Attachments tab.
  3. Add both your .png and .jpeg files.
  4. Set the correct MIME types (image/png and image/jpeg).
  5. Save or remux the file.

Remuxing does not re-encode the video or audio, meaning the process completes in seconds without quality loss.

Media Player and Server Compatibility

Most modern media players and servers—such as VLC Media Player, Kodi, Plex, and Media Player Classic—read MKV attachments natively. When multiple cover files exist, players typically prioritize the primary portrait cover file (regardless of whether it is PNG or JPEG) for library thumbnails, while reserving landscape variants for detailed background views.
