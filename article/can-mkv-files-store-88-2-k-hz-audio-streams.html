Can MKV Files Store 88.2 kHz Audio Streams?

Matroska (MKV) multimedia container files fully support audio streams with non-standard and high-resolution sampling rates, including 88.2 kHz. This article details how the MKV container architecture handles arbitrary audio frequencies, the role of underlying audio codecs, and considerations for playback compatibility.

Matroska Container Architecture and Sample Rates

The MKV container is built upon EBML (Extensible Binary Meta Language), a flexible, binary equivalent of XML. Within the Matroska specification, track headers define the parameters of embedded streams.

For audio tracks, the container defines the sample rate using the SamplingFrequency element (Element ID 0xB5). This value is stored as a floating-point number, which means the specification does not restrict audio to standard industry frequencies like 44.1 kHz or 48 kHz. You can mux audio with sample rates of 88.2 kHz, 176.4 kHz, 96 kHz, 192 kHz, or even arbitrary non-integer values without violating the MKV specification.

The Role of the Audio Codec

While the MKV container can encapsulate any sample rate, the enclosed audio codec must also support the target frequency. Common codecs used within MKV that natively support 88.2 kHz include:

  • FLAC (Free Lossless Audio Codec): Supports sample rates from 1 Hz up to 655,350 Hz in 1 Hz increments, making 88.2 kHz fully compliant.
  • PCM (Uncompressed Audio): Supports arbitrary sample rates natively.
  • ALAC (Apple Lossless Audio Codec): Fully supports 88.2 kHz and other high-resolution rates.
  • TrueHD / DTS-HD Master Audio: Capable of handling high-resolution audio multipliers, including 88.2 kHz and 176.4 kHz.

If the chosen audio format supports 88.2 kHz, the MKV muxer will write both the container-level header and the internal codec bitstream correctly.

Playback and Hardware Compatibility

Modern software splitters and media players—such as FFmpeg, VLC, mpv, and LAV Filters—correctly parse the SamplingFrequency header in MKV files and deliver the 88.2 kHz stream to the audio decoder.

Actual output depends on the playback chain:

  1. Bit-Perfect DAC Playback: If connected to a Digital-to-Analog Converter (DAC) that supports 88.2 kHz via WASAPI Exclusive, ASIO, or ALSA direct hardware output, the file will play natively without alteration.
  2. OS Audio Resampling: If the operating system’s mixer or the playback device does not support 88.2 kHz natively, the audio engine will automatically resample the stream (typically to 48 kHz, 96 kHz, or 44.1 kHz) during playback.
