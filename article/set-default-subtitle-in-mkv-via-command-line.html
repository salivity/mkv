Set Default Subtitle in MKV via Command Line

Setting the default subtitle track in a Matroska (MKV) container does not require slow and quality-degrading video re-encoding. By using the dedicated command-line tool mkvpropedit, which is part of the open-source MKVToolNix suite, you can modify track headers and flags directly within the file in a matter of seconds.

The Tool: mkvpropedit

The standard tool for this task is mkvpropedit. Unlike general media encoders, mkvpropedit modifies existing MKV metadata in place without rewriting the video or audio streams.

Step 1: Identify the Subtitle Track Number

Before setting the default flag, identify the track number of your subtitle stream using mkvmerge:

mkvmerge -i input.mkv

This output displays all tracks in the file. Note the track ID or the subtitle track index (e.g., Track ID 2: subtitles (SubRip/SRT)).

Step 2: Set the Default Subtitle Flag

To set a specific subtitle track as the default, you need to set its flag-default property to 1. If another subtitle track is currently set as default, set its flag to 0.

Example 1: Targeting by Subtitle Track Index

If you want the first subtitle track (s1) to be the default:

mkvpropedit "video.mkv" --edit track:s1 --set flag-default=1

Example 2: Setting Default and Language Simultaneously

To ensure the language code is properly marked (e.g., English) while setting it as default:

mkvpropedit "video.mkv" --edit track:s1 --set flag-default=1 --set language=eng

Example 3: Disabling Previous Defaults

If a second subtitle track (s2) was previously set as the default, you can update both tracks in a single command:

mkvpropedit "video.mkv" --edit track:s1 --set flag-default=1 --edit track:s2 --set flag-default=0

Key Arguments Explained

  • --edit track:sN: Selects the Nth subtitle track in the container (e.g., s1 for the first subtitle track, s2 for the second). You can also target by exact track ID with track:@<ID>.
  • --set flag-default=1: Enables the default flag for playback on the selected track.
  • --set language=<code>: Updates the ISO 639-2 language tag (e.g., eng, spa, fre, ger).
